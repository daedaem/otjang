# 내 얼굴·체형으로 구매 전 모습을 보는 기능

2026-10-11, 한국 시간. **핵심 제품 목표이며 현재 프로토타입에는 구현되어 있지 않다.** 사용자의 우선순위는 구매할 실제 옷을 자기 얼굴·체형에 입혔을 때의 모습을 현실에 가깝게 보는 것이다. 3D는 필수 구현 방식이 아니다. 현재 Blender 옷장과 코디 설명은 이를 대신하지 않는다.

첫 후보는 본인 사진과 상품 사진을 이용하는 **2D 생성형 가상 착장(VTON)**이다. 시각적 인상·실루엣 비교를 목표로 검증하며, 실제 치수·원단 신축성·압박·착용감을 계산하는 물리적 핏 예측과 구분한다. 매력적으로 보이는 합성 이미지가 실제로 잘 맞는 옷의 증거는 아니다.

관련 기술과 공개 구현이 이미 존재한다. ‘다른 곳에서는 못 하는 기능’이라는 시장 우위는 아직 근거가 없다. 우리 제품의 검증 대상은 **사용자 자신과 실제 구매 의류를 얼마나 충실하게 유지하고, 가진 옷·구매 판단에 연결하는가**다.

## 최소 검증: 실제로 가진 옷 10–20착장

1. 정답을 확인할 수 있는 보유 옷으로 시작한다. 본인의 기준 사진과 의류 단독 사진을 입력하고, 같은 옷을 실제 입은 사진은 **결과 비교용으로 따로 보관**한다. 카메라 거리·각도·조명을 가능한 한 맞춘다. 비교용 착용 정답을 모델 입력에 섞지 않는다.
2. 먼저 한 벌씩 바꾸는 상의·하의로 평가한다. 셔츠 칼라·체크/줄무늬·로고·재킷 라펠·바지 길이를 포함하고, 팔이 가린 경우·여유 있는 옷·겹쳐 입기는 별도 실패 조건으로 기록한다. 지원하지 않는 신발·복수 의류 동시 교체를 지원한다고 표시하지 않는다.
3. 입력·모델 버전·설정·시드를 고정해 비교하고, 최소 두 시드의 결과와 실패 결과도 남긴다. 잘 나온 한 장만 골라 평균 품질로 소개하지 않는다.

| 평가축 | 실제 착용 사진과 확인할 차이 |
| --- | --- |
| 본인 유지 | 얼굴·머리·피부·체형·어깨/허리 비율이 다른 사람처럼 바뀌지 않는가 |
| 의류 유지 | 색·무늬·로고·깃·주머니·단추·라펠이 다른 제품으로 변하지 않는가 |
| 착장 위치 | 소매·밑단·허리선·가림·겹침이 실제와 얼마나 다른가 |
| 구매 판단 실패 | 실제로 짧거나 조이는 옷을 자연스럽게 늘리거나 몸을 바꾸어, 잘 맞는 것처럼 보이게 하지 않는가 |
| 실사용 | 준비 시간·실패/재시도·GPU 시간·건당 비용을 감당할 수 있는가 |

각 축을 ‘사용 가능 / 수정 필요 / 오판 위험’으로 따로 기록한다. 실제 길이·여유가 틀리면 화질이 좋아도 실패다. 초기 10–20건은 문제를 찾는 검증이며 일반 사용자 정확도나 사이즈 보장 수치가 아니다. 본인이 실제 착용과 비교해 구매 판단에 도움이 되는지 평가한 뒤 사용 범위를 정한다.

## 지금의 구현 경계와 다음 결정

현재 앱은 유형별 옷 모형·사진 기록·코디·수동 구매 후보 비교를 제공한다. **본인 얼굴·체형에 상품을 입히는 생성, 실제 핏 예측, VTON 서버는 없다.** 저사양 PC에 모델 설치를 요구하지 않는 방향을 유지한다. 연구용 생성 결과를 미리 저장해 보여 주는 경로와 서버 추론의 비용·라이선스를 비교한 뒤 연결 방식을 결정한다. CPU 웹서버가 있다는 이유로 생성형 이미지 모델의 GPU 비용까지 충당된다고 가정하지 않는다.

개인 사진은 기존 로컬 보관 원칙을 유지한다. 실제 외부 추론 경로를 선택할 때 전송 대상·보관·삭제 범위를 정한다. 이번 조사나 요구 정리를 사진 전송 승인으로 처리하지 않는다. 비용은 텍스트 코디의 토큰 추정과 분리해 이미지 생성당 GPU 시간·재시도 기준으로 측정한다.
