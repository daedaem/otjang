[원스톱 제품·개발 계약](onestop-product-contract-20261014.md)의 전체 목표를 항목별로 나눠, 지금 어디까지 되었는지 기록한다. 외부 설정·계약·운영자 정보가 필요한 항목은 정확히 무엇이 필요한지 적는다.

## 먼저 알아 둘 것

- **병합된 것은 없다.** 아래의 "구현됨"은 모두 열린 PR 안에 있으며, master에 병합되거나 배포되지 않았다.
- PR 스택은 다음 순서로 쌓여 있고, 모두 OPEN·미병합이다.
  - master ← #11 ← #16 ← #17 ← #18 ← #19 ← #20 ← #21 ← #22 ← 회원 코디 PR(`claude/community-20261015`)
- **실제 휴대폰에서 확인한 항목은 없다.**
  - 확인 방법은 Node 자동 검사(대역 DOM·fake IndexedDB·실제 서버 프로세스)와 데스크톱 Chromium 390×844 화면 확인이다.
  - iOS Safari, Android Chrome, 실제 카메라, 실제 사용자 사용은 확인하지 않았다.
- 상태 구분:
  - **구현됨**: 코드와 회귀 검사가 PR에 있고, 외부 설정 없이 동작한다. 실기기 확인은 안 됐다.
  - **실사용 미검증**: 기능은 있지만 품질이나 효용이 실제 사진·사용자·장기 사용에 달려 있어 아직 판단할 수 없다.
  - **외부 연결 필요**: 구조와 화면은 있지만 키·계약·운영자 정보·장비가 있어야 실제로 동작한다.
  - **미구현**: 아직 코드가 없다.

## 가상 착용 결정 (사진은 내 PC·내 클라우드에서만)

- 지금 있는 것은 `experiments/vton-fashn-1.5`의 로컬 시험 도구다.
  - 공식 예제 이미지로 클라우드 CPU에서 리허설했다. 한 장에 약 44분, 최대 메모리 7.3GB였다.
  - M1 맥에서의 실제 측정은 아직 없다.
- 앱에 넣으려면 다음 세 가지를 먼저 정해야 한다.
  1. **장비**
     - 맥 CPU에서 한 장에 수십 분이 걸리면 앱 기능으로 쓸 수 없다(추정).
     - NVIDIA GPU가 있는 내 PC를 쓰거나, 내 클라우드 GPU를 쓰는 방법이 있다.
     - 클라우드 GPU는 유료라서, 비용 목표 0원을 바꿀지 별도 결정이 필요하다.
  2. **라이선스**
     - FASHN VTON 코드·가중치와 DWPose는 Apache-2.0이다.
     - 사람 분할 모델(fashn-human-parser)은 NVIDIA Source Code License로 **비상업만** 허용된다. 서비스에 쓰려면 이 모델을 바꿔야 한다.
  3. **사진 정책**
     - 전신 사진은 얼굴이 들어가는 민감한 사진이다.
     - 내 서버에서만 처리하고, 처리 뒤 바로 지우고, 결과를 저장할지는 사용자가 고르게 하는 정책을 정해야 한다.
- 추천 순서
  1. **맥에서 시험 도구로 내 사진 1장을 돌려 보기(0원, 지금 가능).** 품질이 쓸 만한지가 모든 결정의 전제이기 때문이다.
  2. 품질이 쓸 만하면 GPU가 있는 내 PC에 같은 서버를 두고, 배경 지우기처럼 "동의 후 내 서버에서만 처리" 구조로 붙인다.
  3. 사람 분할 모델 교체는 상용화 전까지 미룬다.
- 결과 화면을 핏이나 사이즈 보장으로 쓰지 않는다는 계약은 그대로다.
