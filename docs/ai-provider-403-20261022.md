# 비공개 AI 403 진단 및 수정 — 2026-10-22

> **현재 기준(2026-10-23):** PR #47은 master `90889b7`에 병합·비공개 배포됐고, 마지막 10-22 검증에서 실제 AI 총 5회가 연속 성공했다. 아래 진단 단계의 4회와 최종 배포 후 추가 1회를 구분한다. 최신 구조·운영 절차는 [시스템 인수인계](system-handover.md), 다음 작업은 [문서 안내](README.md)를 먼저 본다. 아래 날짜별 대기/실패/검사 수는 당시 기록이며 최신 상태로 소급 해석하지 않는다.

## 요청과 범위

대표 요청: “AI 403 오류도 해결해서 실제로 추천받을 수 있게 마무리”. 최신 master `5251d4e`(Claude PR #45 포함)에서 작업했다. 키 교체·모델 변경·한도 확대·자동 재시도·인증 해제 없이 진단했다. 공개 출시나 사진 전송을 승인받은 것으로 해석하지 않는다.

## 확인한 사실

- 기본 배치에서 같은 공개 후보 비교 요청이 HTTP 403으로 실패했다. SDK 오류의 허용된 필드만 추려 보니 `type=forbidden`, JSON 응답, 제공자 `cf-ray`의 지역 접미사 `HKG`였다. `permission_error`나 401이 아니며 요청 ID도 없었다.
- Cloudflare 공식 배치 기능 `placement.region=aws:ap-northeast-2`를 지정해 서울 인근에서 실행하도록 변경했다. 실제 버전 메타데이터에서도 `placement_mode=targeted`, 해당 region을 확인했다.
- 진단 버전 `e5d91ef3-63b4-47d4-a42f-cf076b98a19b`에서 403을 재현했다. 서울 배치 버전 `c3d760c6-c624-40ad-a5ab-9952017dc8bf`에서 동일 공개 후보 비교 2회, 상담 1회, 이어 묻기 1회가 연속 성공했다.
- 공개 후보 비교: “유니클로 티셔츠”, 실제 모델 `claude-haiku-5-5`, 입력/출력 토큰 598/469 및 598/585. 서로 다른 실제 응답 ID를 확인했다.
- 상담: “출근용 셔츠 10만원 이하로 추천해줘”, 실제 모델 `claude-haiku-5-5`, 입력/출력 2425/872. 무신사 스탠다드·토마스모어의 실제 카탈로그 상품 카드가 표시됐다. 이어 “그중 하나만 골라줘. 5만원 이하로.”에 무신사 스탠다드 릴렉스 핏 옥스포드 셔츠 [블루], 수집가 33,890원 카드와 답변을 확인했다.
- 성공은 브라우저 화면의 실제 SDK 응답 메타데이터와 Anthropic Console 최신 성공 로그의 모델·토큰·요청 ID를 서로 대조했다. 4건 모두 성공 로그가 있고, 이어 묻기는 입력/출력 2705/887이었다. 정해 둔 문구나 가짜 응답으로 대체하지 않았다. 전체 응답·요청 ID는 공개 Git 문서에 넣지 않는다.

## 판단과 한계

HKG 경로의 거절 후 배치만 바꿔 반복 성공했으므로, 기본 실행/연결 경로가 이번 403의 원인이라는 가설을 지지한다. HKG 접미사는 제공자 응답 경로의 관찰값이다. 제공자 내부 차단 규칙이나 IP 지리 판정까지 확인한 것은 아니므로 “홍콩 IP 차단 확정”이나 “키 권한 문제 확정”이라고 쓰지 않는다. 배치 힌트는 물리 위치를 영구 보장하는 데이터 주권 기능도 아니다.

진단 배포의 4건(아래 최종 master 배포 후 1건을 더해 총 5건)의 연속 성공은 해당 시점 기능 검증이며 장기 가용성·실제 iPhone 검증은 아니다. 최초 상담 문장에는 50,960원을 10만원 예산보다 넘는 것처럼 설명한 오류가 있었다. 연결 성공과 추천 내용의 정확성을 구분해야 하며, 가격 조건 설명의 서버 검증은 별도 개선 과제다. 후속 5만원 질문의 33,890원 선택은 조건에 맞았다. 현재가·재고·핏은 보장하지 않는다.

## 운영 보존 및 재현

- 공식 Anthropic API와 기존 Secret 사용을 유지한다. 키 값을 읽거나 로그·Git·브라우저 코드에 넣지 않았다.
- `maxRetries=0`, 15초 SDK 제한, 기존 공유 D1 예산(일 100/월 300/분 5)을 유지한다. 실패 요청도 사용 예약에 포함된다.
- 실패 로그는 status, 허용된 오류 type, json/html 분류, 검증한 요청 ID, 검증한 3글자 지역 코드만 기록한다. 원문 오류·헤더 전체·질문·옷장·IP·키는 기록하지 않는다.
- 사용자의 원래 옷장·구매 기록·백업 형식·개인 사진은 수정하지 않는다. Claude #45의 상담 후보/이력/550자 처리도 유지한다.
- 403 안내를 “API 사용 권한을 확인”으로 단정하지 않도록 수정하고 상담에도 제공자 오류 안내를 추가한다.
- 재발 시 먼저 이 제한된 로그와 배포 version/placement를 대조한다. 무제한 재시도나 다른 프록시로 우회하지 않는다. 필요하면 허용된 요청 ID로 제공자에게 원인 확인을 요청한다(외부 문의 발송은 별도 사용자 지시).

## 자동 빌드 설정 정정

PR #47의 Cloudflare 기능 브랜치 빌드가 `/opt/buildhome/repo/package.json` 없음(ENOENT)으로 실패했다. 프로덕션 설정의 루트는 이미 `app/lite`였지만 프리뷰 기본 루트는 `/`였다. Cloudflare 설정에서 프리뷰 기본 루트를 `app/lite`, 명령을 `npx wrangler deploy --dry-run`으로 저장했다. 새 프리뷰 배포나 별도 접근 주소를 만들지 않고 빌드 검증만 하려는 설정이다. 프로덕션 `master`/`app/lite`/`npx wrangler deploy`와 프리뷰 URL 비활성화는 유지했다.

프리뷰의 빌드 명령은 `OTJANG_PRIVATE_DEPLOY=owner-approved PRIVATE_AUTH_MODE=session npm run build`로 지정했다. 기존 배포 보호 장치의 비공개 승인 조건을 사용하며 `OTJANG_ALLOW_PUBLIC_DEPLOY`는 설정하지 않는다. 이 단계는 산출물만 만들고, 후속 `--dry-run`으로 끝나므로 프리뷰 Secret이나 새 인증정보도 추가하지 않는다.

기본값 정정 뒤에도 이미 생성된 기능 브랜치의 개별 설정에는 루트 `/`가 남아 있었다. **프리뷰 기본 설정과 기존 브랜치 설정을 모두** 루트 `app/lite`, 위 빌드 명령, `npx wrangler deploy --dry-run`으로 바꿨다. 기본값 변경은 기존 브랜치 override에 소급 적용되지 않는다. 같은 head `377ca71`의 재검증 빌드 `7c098612-7026-43bc-8bef-be6ade76321f`에서 올바른 경로·명령과 자산 `55e80bddc6a1`을 확인했다. [설정 정정 댓글](https://github.com/daedaem/otjang/pull/47#issuecomment-6339841323).

## 최종 master 배포와 추가 실호출 (2026-10-22)

- [PR #47](https://github.com/daedaem/otjang/pull/47)은 검사 7개 통과 후 master `90889b7e11f9d9d223cd8d468c87402b49536fb4`에 병합됐다. master의 앱·서버·Docker 검사와 Cloudflare 자동 빌드도 성공했다.
- 마지막으로 확인한 활성 버전은 `14e6fd7b-8900-49b5-8d3c-4455aec74a49` 100%다. 같은 master의 수동 배포 `ee5cb989-4c32-444a-971b-8e48b4183755`와 script ETag·바인딩 이름이 같고 서울 배치가 유지됐다. 자산은 `55e80bddc6a1`이다. **이것은 10-22 관찰이며, 10-23 문서 정리에서 오늘 활성 버전을 다시 조회한 것은 아니다.**
- 최종 배포 후 “그 셔츠에 어울리는 바지도 5만원 이하로 하나만 추천해줘”에 무신사 스탠다드 스포티브 스트레이트 슬랙스 [블랙], 수집가 21,890원 카드와 설명을 받았다. SDK 모델은 `claude-haiku-5-5`, 입력/출력 2607/1274토큰이었다. 실제 제공자 로그와 대조했으며 서울 배치 후 총 **5회 연속 성공**이다. 전체 제공자 요청 ID는 적지 않는다.
- 미인증 API 요청은 계속 401이었다. 키 값·개인 사진을 Git/진단에 추가하지 않았고 진단 tail은 종료했다. 50,960원 예산 설명 오류는 이 네트워크 수정으로 해결됐다고 주장하지 않는다.
- 같은 10-22 작업 대화의 후속 도구 실행에서 `wrangler logout`의 `Successfully logged out`을 확인했다. 이는 PR 완료 댓글 이후 실행 증거이며 이번 문서 정리에서 새로 CLI 인증 상태를 조회한 것은 아니다. 로컬 배포 인증 종료는 앱의 본인 세션이나 서버 Secret 삭제가 아니다.

위 배포·실호출 결과는 [최종 완료 댓글](https://github.com/daedaem/otjang/pull/47#issuecomment-6339905634)을 저장소에서도 읽을 수 있도록 옮긴 것이다. 장기 가용성·실물 iPhone·일반 공개 출시 완료와 구분한다.
