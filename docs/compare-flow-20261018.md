# 비교 → 구매처 → 기록 흐름 손질 (2026-10-18)

대표 지시의 "검색→비교→구매처→보유·반품 기록의 전체 흐름 개선" 중, 전문가 역할 모의 평가(구매 전환 PM, 모바일 리드)에서 나온 막다른 곳 네 가지를 고쳤다.

| 문제 | 수정 |
|---|---|
| 긍정 판정("○○ 코디가 새로 연결돼요")이 글자 한 줄뿐이고 내 옷과 후보의 조합은 접힌 곳에만 있음 | 판정 바로 아래에 첫 코디의 구성(내 옷 사진 + 이 후보)을 펼쳐서 보여 준다 |
| 예시 옷장 상태에서 "내 옷 넣고 비교하기"를 누르면 보던 상품이 사라지고 등록 화면만 열림 | 등록 화면 맨 위에 보던 상품 띠("이 상품과 비교하려면 실제 옷을 한 벌만 넣으면 돼요. 저장하면 비교로 돌아가요")를 고정하고, 저장하면 그 상품의 비교(판정) 화면으로 자동 복귀한다(`draft.returnProductId`) |
| "판매처·배송비 포함 총액 비교"는 판매처가 1곳이라 늘 빈 화면이고, 닫으면 판정 화면이 아니라 홈으로 감 | 버튼을 "다른 판매처 가격 직접 기록·비교" 링크로 바꾸고 "지금 연결된 판매처는 무신사 1곳, 가격은 수집일 기준"을 적는다. 하위 시트를 닫으면 판정 화면으로 돌아간다 |
| 받은 뒤에도 총액 비교 버튼·"이미 있나요?" 질문이 남음 | (앞 커밋) 후보 단계에서만 보인다 |

가격 기록 기능과 저장 형식은 그대로다. 실시간 최저가·주문 연동은 만들지 않았다.

## 확인 (모바일 390×844, 클라우드 Chromium)
- 예시 옷장 → 상품 → "내 옷 넣고 비교하기": 등록 화면 위에 보던 상품 띠. 사진 없이 종류 하나 골라 저장 → 같은 상품의 판정 화면으로 복귀.
- 실제 옷 3벌(블루종·셔츠·치노) → 로퍼 비교: "아이비 캠퍼스 코디가 새로 연결돼요" 아래 코디 구성 줄, 진한 버튼은 "사기로 할게요".
- 판매처 가격 시트 → 닫기 → 판정 화면 유지.
- 실제 옷 3벌(셔츠·치노·흰 스니커즈) → 블레이저 비교: 판정 아래 코디 구성 줄 표시, 판매처 1곳 안내 표시.
- 검사 598개 통과.

## 미검증·한계
- "한 벌 넣고 다시 비교"에서 사진 없이 종류만 넣는 등록 화면의 단계 수는 줄이지 않았다(Codex 로컬의 등록 종류 목록 통일과 겹칠 수 있어 손대지 않음).
- 실기기·Windows 미검증.
