# 상용화 시 AI 비용 추정

확인일: **2026-10-11, 한국 시간**. 아래 단가는 당일 공식 API 요금표에서 직접 확인했다. 현재 개인 프로토타입은 모델 API를 호출하지 않는다. 이 문서는 상용화 검토용이며 유료 서비스 도입 결정이 아니다.

## 같은 사용량으로 비교

**가정:** 사용자 1명당 월 10회 분석, 회당 입력 6,000토큰·출력 **과금 대상 총 1,500토큰**, 환율 **1달러=1,400원**. 실제 이용량·현재 환율을 측정한 값은 아니다. 출력 예산에는 과금되는 추론 토큰도 포함해야 한다. 캐시 할인·Batch 할인·무료 이용분·약정 할인은 적용하지 않았다.

`월 비용 = 사용자 수 × 10 × (6,000 × 입력 단가 + 1,500 × 출력 단가) ÷ 1,000,000 × 1,400`

| 모델 | 입력 USD/100만 토큰 | 출력 USD/100만 토큰 | 1명/월 | 100명/월 | 1,000명/월 |
| --- | ---: | ---: | ---: | ---: | ---: |
| OpenAI GPT-6 Luna | $0.10 | $0.50 | 18.9원 | 1,890원 | 18,900원 |
| OpenAI GPT-6.1 Sol | $2.00 | $10.00 | 378원 | 37,800원 | 378,000원 |
| OpenAI GPT-6 Astra | $10.00 | $50.00 | 1,890원 | 189,000원 | 1,890,000원 |
| Claude Haiku 5.5 | $0.10 | $0.50 | 18.9원 | 1,890원 | 18,900원 |
| Claude Sonnet 5.5 | $2.00 | $10.00 | 378원 | 37,800원 | 378,000원 |
| Claude Opus 5.5 | $4.00 | $20.00 | 756원 | 75,600원 | 756,000원 |
| Gemini 3.5 Flash-Lite | $0.30 | $2.50 | 77.7원 | 7,770원 | 77,700원 |
| Gemini 3.8 Flash | $0.75 | $3.75 | 141.75원 | 14,175원 | 141,750원 |

OpenAI는 **Standard·Short context**, Claude는 **Base tokens** 단가다. Haiku 5.5는 프롬프트 100,000토큰 이하에 적용된다. Gemini는 **Standard Paid Tier**이며 출력 단가는 thinking tokens를 포함한다. Gemini 3.8 Flash 요금은 **2026-12-31까지**이며, 공식 페이지는 2027-01-01부터 입력 $1.50·출력 $7.50을 공지했다. 같은 가정에서 월 1명 283.5원, 100명 28,350원, 1,000명 283,500원이다.

## 실제 상품을 찾으면 추가되는 비용

위 표에는 **사진 입력 토큰, 검색, 재시도, 출력 예산을 초과한 추론 토큰, 세금, 웹서버·DB·사진 저장·트래픽 비용**을 넣지 않았다. 실제 옷장 추천과 구매 상품 발견은 호출 수와 입력량이 다르다.

- OpenAI·Claude의 웹 검색은 공식 표 기준 **검색 1,000회당 $10**, 검색 내용의 모델 토큰 비용은 별도다. 분석당 검색 3회를 가정하면 1인 월 30회, 검색 호출료만 $0.30, 가정 환율로 **420원**이 추가된다.
- Gemini 3.x 이상 Google Search grounding은 해당 모델들이 공유하는 월 5,000회 무료 이용분 이후 **1,000회당 $14**다. 실제 요청의 검색 과금 단위와 무료 잔여량은 구현 시 확인한다.
- 상품 카탈로그·후기 데이터 제공사 비용은 별도다. 검색 API를 쓴다고 가격·재고·동일 상품·핏 정보가 검증되는 것은 아니다.

Codex·Claude·Gemini를 쓰는 개발자/대화 서비스 구독과, 고객 요청을 처리하는 상용 앱 API는 **서로 다른 이용량·청구 항목으로 예산을 잡는다**. 구독에 포함되는 크레딧·연결 혜택이 있다면 해당 계정의 최신 적용 조건을 확인해 차감한다. 개인 구독 하나로 모든 고객의 AI 비용을 충당한다고 가정하지 않는다.

## 이미 웹서버가 있을 때 자체 LLM

웹사이트용 CPU 서버가 있다는 점은 공통 비용을 줄이지만 모델 추론 자원이 무료가 된다는 뜻은 아니다. 작은 양자화 모델은 남는 CPU·RAM으로 실행할 수도 있다. 다만 응답 시간과 동시 요청을 감당하는지 확인해야 하며, GPU를 붙이면 VRAM·GPU 이용료·전력·운영 부담이 추가된다.

비교할 추가 비용은 `장비 월 상각 또는 GPU 임대료 + 전력 + 추가 메모리·저장 + 배포·장애 대응 비용`이다. 기존 서버의 여유 자원을 쓰더라도 다른 요청을 처리할 용량이 줄어든다. 이번 조사에서는 특정 GPU 호스팅 업체의 현재 견적을 확인하지 않았으므로 임대 단가나 손익분기 사용자 수를 확정하지 않는다. 처리량·지연시간을 측정한 뒤 동일한 서비스 품질과 가동 시간으로 API 비용과 비교한다.

## 모델 선택 전에 확인할 품질

저가 모델이 이 제품에 충분한지는 아직 검증하지 않았다. 본인이 알고 있는 **코디 20개**로 같은 입력을 주고, 보유 옷 준수·원하는 스타일·구매 보완 이유·모르는 정보의 처리·응답 시간을 비교한다. 체형과 실제 핏은 실측·착용 후기 없이 확정하지 않는지도 확인한다. 가격이 낮거나 모델이 크다는 이유만으로 최종 모델을 선택하지 않는다.

## 공식 출처

- [OpenAI API pricing](https://developers.openai.com/api/docs/pricing/): Flagship models의 Standard·Short context 표, Tools의 Web search. 기존 `openai.com/api/pricing/` 주소는 Business 요금 페이지로 이동해 API 단가 근거로 쓰지 않았다.
- [Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing): Model pricing의 Base tokens 표, Web search tool.
- [Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing): 각 모델의 Standard Paid Tier, Google Search grounding 및 요금 변경일.

요금표는 변경될 수 있다. 공개 전에는 사용할 모델 ID·서비스 등급·토큰 과금·검색 단위를 다시 확인하고, 실제 요청 로그의 사용량으로 추정치를 갱신한다.
