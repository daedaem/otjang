구현 상태 갱신: 2026-10-29. 인수 기준 master는 c02ebd4(#132)다. 기존 React 이전·사진 등록/링크 비교·회원별 기기 보관/설치 갱신과 실제 AI3회에 더해, 독립 커뮤니티의 코디·세일 정보·자유게시판/수정·신고·운영/안전한 나가기와 전용 DB를 비공개 앱에 반영했다. 담당은 GPT/Codex이며 [개발 계획](development-plan.md)과 [시스템 인수인계](system-handover.md)의 실제 CI/배포/확인 경계를 따른다. 사업 방향은 아래 원스톱 목표 그대로다. 실제 추천 품질·구매 효용·회원/소셜·메일 성공·실물 폰·상품/이미지·상업 날씨 권리·공개 운영은 완료로 처리하지 않는다. 세일 정보는 작성자 제보이며 확인된 현재 가격·재고·최저가 공급망이 아니다. 아래 과거 운영 증거와 현재 구현을 구분한다.

## 서비스가 하려는 일

**대충 말해도 나에게 맞는 실제 옷을 골라 주고, 내 옷과 비교해 새 상품·중고 구매 및 구매 후 기록까지 이어 주는 원스톱 패션 서비스다.**

옷장 등록은 선택이다. “출근용 셔츠 10만원 이하”처럼 묻기만 해도 시작할 수 있어야 한다. 옷장이 있으면 이미 가진 비슷한 옷, 새로 생기는 조합, 실제 착용·반품 기록을 더해 판단을 돕는다. 같은 정보를 다른 앱에서 다시 입력하며 탐색·비교를 처음부터 반복하는 불편을 줄이는 것이 목적이다.

원하는 고객 흐름은 다음과 같다.

1. 말로 요청하거나 보고 있는 상품을 가져온다. 종류·예산·상황 등 알아들은 조건과 모르는 조건을 구분한다.
2. 실제 브랜드·상품명·출처·확인 시점의 가격과 추천 이유를 본다. 맞는 상품이 없으면 없다고 안내한다.
3. 필요하면 옷장을 넣어 중복과 어울리는 조합을 비교한다. 등록하지 않아도 상품 탐색·판매처 이동은 가능해야 한다.
4. 새 상품과 국내외 중고를 함께 검토하고 사용자가 구매를 결정한다. 서로 다른 옵션·상태의 상품을 같은 상품 최저가로 오인하게 하지 않는다.
5. 주문·수령·보유 확정·착용·반품을 기록하고 다음 추천·옷장에 연결한다. 사용자 직접 기록과 판매처가 확인한 거래는 구분한다.

[원스톱 제품 계약](log/2026-10/onestop-product-contract-20261014.md)의 전체 목표는 유지한다. 사진 식별, 가상 착용, 정확한 상품·옵션·가격 비교와 확인된 주문 이벤트는 보류·외부 의존성이 있어도 목표에서 삭제하지 않는다. 자체 결제와 직접 구매 플랫폼 역할은 장기 확장이다.

## 차별화 가설과 검증

추천→내 옷 비교→새 상품·중고 선택→구매 후 기록을 이어 가면 반복 입력과 후회 구매가 줄고 다시 사용할 이유가 생길 것이라는 **가설**이다. 여러 쇼핑몰에서의 중립적 판단과 기록의 연속성이 유용할 수 있으나, Acloset·채팅 AI·쇼핑앱보다 낫다는 결론은 아직 없다. 제휴 수수료 때문에 판단을 특정 판매처에 유리하게 바꾸지 않는 원칙을 지킨다.

- 대표의 실제 요청으로 옷장 없이 첫 추천을 받고 판매처를 확인하는 과제를 먼저 관찰한다. 옷장을 넣었을 때 추가로 얻는 판단도 구분한다.
- 같은 구매 고민을 기존 방법·현재 앱으로 처리해 조건 유지, 실제 후보·옵션 보존, 반복 입력, 도움이 된 근거와 막힌 지점을 기록한다.
- 사용자의 직접 주문·착용·반품 기록이 다음 화면에 정확히 돌아오는지 확인한다. 링크 클릭을 구매로, 기록 0회를 미착용으로 세지 않는다.
- 외부 파일럿 모집·유료 실험은 별도 승인 뒤다. 재사용·지불 의향·매출·시장성·경쟁 우위는 실제 증거 전까지 미검증이다.

옛 문서의 5벌 등록 활성화율, 25% 재요청, 송금 5명, “열 번째 구매부터 우위”는 현재 서비스의 합격 기준으로 확정된 숫자가 아니다. 외부 실험을 시작한다면 옷장 없는 시작도 평가하고 사람 수·요청 수·기간·판정 기준을 미리 정해야 한다. 실제 인간 전문가 자문·독립 투표·수상 디자이너 참여가 있었던 것처럼 표현하지 않는다. 저장소의 역할별 AI 검토는 모의 검토다.

## 아직 대표 결정 또는 외부 확인이 필요한 것

공개 출시 시점과 대상, 유료 사용·충전, 이름·상표, 상품 공급자별 상용 표시·저장·AI 처리 조건, 중고 파트너 문의·계정, 공개 커뮤니티 운영 정책은 해당 승인·근거가 생겨야 확정한다. 이미 승인된 동의형 사진 등록·게시 사진 전송을 전체 개인 사진의 포괄 전송 승인으로 넓히지 않는다. 기존 승인으로 가능한 비공개 오류 수정·검증은 계속하되 이 목록을 포괄 승인으로 해석하지 않는다. 다음 작업은 [개발 계획](development-plan.md)을 따른다.
