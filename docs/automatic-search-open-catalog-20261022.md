# 한 번 검색 · 공개 상품 DB · AI 후보 비교 (2026-10-22)

## 대표 결정과 완료 범위

대표 요청: “불러오기 없이 바로 검색되게 개선하고 DB에 저장해서 AI 추천에 쓸 수 있는 공급처를 찾아 연결”. 이슈 [#42](https://github.com/daedaem/otjang/issues/42). 기존 본인 전용 배포·D1·AI 한도 안에서 진행하며, 개인 원본·기존 저장 키·구매 기록·Secret은 변경하지 않는다. 외부 공개 출시는 별도다.

## 공급원 판단

| 공급원 | 확인한 근거 | 이번 적용 |
|---|---|---|
| Open Products Facts | 공급자가 게시한 [데이터 설명](https://www.data.gouv.fr/datasets/open-products-facts)은 상업 재사용과 ODbL 조건을 명시. [ODbL 3.1, 4.2~4.7](https://opendatacommons.org/licenses/odbl/1-0/)은 추출·영구 복제·파생 DB와 출처/동일조건/기계판독본 제공을 규정 | 이미 받은 실제 의류 194건을 별도 D1 DB 영역에 저장·검색. 확인된 브랜드·이름·분류만 AI 후보 비교에 사용. 원문·출처·DB 다운로드 유지 |
| Awin | [공식 피드 안내](https://help.awin.com/developers/docs/product-feed-publisher-guide-intro)는 패션 포함 상품명·가격·사진·구매 링크 피드와 갱신을 안내. [가입 FAQ](https://www.awin.com/gb/faqs)는 약관과 심사를 요구. 판매자별 programme terms도 적용 | 공급 후보. 대표 계정·제휴 승인·대상 판매자 조건/외부 AI 범위 확인 전 연결하지 않음. 가입만으로 모든 브랜드를 쓰는 무료 API라고 안내하지 않음 |
| Open Icecat | [현행 무료 라이선스 10조](https://iceclog.com/open-content-license/)는 기계학습/합성 콘텐츠 생성 및 생성형 AI 프레임워크 상업 이용을 제한 | 무료 AI 추천 공급원으로 채택하지 않음 |
| Wikidata | [공식 데이터 접근 안내](https://www.wikidata.org/wiki/Help:Data_access)는 구조화 데이터 CC0 | 브랜드·분류 사전 후보. 현재 구매할 의류 SKU·가격·재고 공급을 확인하지 못했으므로 판매 상품 수를 늘린 것으로 표시하지 않음 |
| 애드픽·Rakuten | 기존 공식 키워드 검색 연결. 저장·가공·상품별 외부 AI 범위는 별도 확인 필요 | 애드픽 검색은 자동 실행. 상품 DB 복제/AI 후보 전송은 추가하지 않음 |

OPF의 AI 비교 채택은 위 재사용 라이선스에 대한 구현 판단이다. 공급자가 개별적으로 앱 또는 외부 LLM 사용을 심사·승인한 사실은 아니다. 모델 학습·사진 재사용은 구현하지 않는다. 공식 라이선스 안내의 [DB/내용/사진 구분](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/)도 유지한다. 국내 판매 상품·가격·재고가 풍부한 무심사 무료 피드와 외부 AI 권한을 모두 확보한 결과는 아니다.

## 구조와 선택 이유

- 고객이 검색을 제출하면 국내 API를 한 번 조회한다. 옷장 등록의 자동완성은 기존 로컬 데이터로 유지한다. 외부 API를 타이핑마다 호출하지 않는다. 같은 키워드의 진행 중 요청만 공유하고 완료한 애드픽 결과를 localStorage/DB에 보관하지 않는다. 실패 시 재시도만 제공한다.
- 화면을 떠난 뒤의 늦은 응답은 폐기한다. 기존 목록이 모르는 단어/조건을 빼고 다른 브랜드를 보여 주던 문제도 화면에서 차단한다. 국내 조회는 요청 전체를 그대로 보내며 예산·핏·코디 미적용을 알린다. 0건과 오류를 구분한다.
- `open_product_facts`와 `open_product_snapshots`에 공개 데이터만 저장한다. 배포에 포함한 스냅샷 SHA256을 키로 쓰고 최초 본인 인증된 조회에서 트랜잭션으로 넣는다. 20행씩 묶어 D1 무료의 호출당 50개 쿼리/문장당 100개 바인딩 제한 안에 둔다. [Cloudflare 한도](https://developers.cloudflare.com/d1/platform/limits/).
- 이후 서버 검색과 내보내기는 실제 DB 행을 읽는다. 다른 상품·사용자 자료를 덮어쓰거나 지우지 않는다. 스냅샷 갱신은 유지보수 명령으로만 하며 실시간 전 상품 수집/백그라운드 크롤링은 없다. 기존 스냅샷을 자동 삭제하지 않는다.
- `GET /api/open-products?q=...`는 검색, `/api/open-products/export`는 전체 사용 DB/출처/ODbL을 제공한다. 둘 다 본인 인증이 필수다. 공개 사용 시에도 수신자가 라이선스대로 재사용할 수 있도록 JSON을 제공하는 구조다.
- `/api/rank`의 `open_rank`는 질문과 최대 12개 숫자 코드만 받는다. 임의의 상품 사실·가격·사진·옷장·대화 이력을 받지 않는다. 서버 DB에서 코드를 검증한 뒤 기존 공유 일/월/분 한도를 예약하고 Claude에 공개 텍스트만 보낸다. 모델·한도를 늘리지 않는다. 응답의 미등록/중복/누락 코드와 추가 가격 필드는 거절한다. 후보 0~1개는 AI 호출하지 않는다.
- 가격·재고·소재·정확한 핏·개인 코디 근거가 없으므로 이름·브랜드·공급자 분류에 따른 ‘추가 확인할 후보 비교’로 표시한다. 원본 링크는 구매 링크가 아니다. AI 문장은 틀릴 수 있고 원본으로 확인해야 한다. 결과를 상품 사실 DB에 저장하지 않는다.

## 검증과 운영 상태

- 로컬 SQLite 실제 SQL: 194행 저장, 동시/반복 호출 멱등성, 개인 자료 대용 sentinel 보존, 검색/전체 내보내기 일치, 미인증/DB 실패, 모르는 코드·중복·가짜 가격 차단 검사.
- 브라우저 로컬 합성 QA: `유니클로 티셔츠` 입력만으로 외부 API 0회, 제출 후 국내 조회 1회/공개 DB 조회 1회 확인. 추천 화면에서 실제 OPF 후보 2개와 **합성 AI 응답**을 표시했다. 이 관찰은 실제 애드픽/Anthropic 성공 증거가 아니다.
- 전체 lite 검사 132개 통과(새 동작 추가 후). 빌드·Wrangler dry-run 통과. 최종 커밋 검사/배포/운영 실증은 아래 실행 기록에 이어 적는다.
- 아이폰 실기기·공개 출시·상용 상품 공급 계약은 미완료다.
