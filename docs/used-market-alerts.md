# 「찾는 중」 자동 알림 — 공식 경로 조사

작성: 2026-11-15, Claude. [서비스 의도](intent.md) 2번("당근 같은 중고에 올라오기를 기다려 주기")을 실제로 만들 수 있는지, 각 판매처의 **공식** 경로만 조사했다. 웹 검색과 eBay 개발자 문서 2쪽을 읽은 결과이고, 각 회사에 문의하거나 약관 원문을 끝까지 읽은 것은 아니다.

## 결론

| 판매처 | 공식 검색 API | 지금 할 수 있는 것 | 자동 알림 |
|---|---|---|---|
| eBay | **있음**(Browse API `item_summary/search`, 새 매물순 정렬 지원) | 검색 링크 | 가능성 있음. 단 운영 사용은 eBay 파트너 승인(EPN 가입 → 사업 모델 심사)이 필요하고 승인은 보장되지 않는다 |
| 당근 | 공개 문서를 찾지 못함 | 검색 링크 | 불가(공식 경로 미확인) |
| 번개장터 | 공개 문서를 찾지 못함 | 검색 링크 | 불가(공식 경로 미확인) |
| 중고나라 | 공개 문서를 찾지 못함 | 검색 링크 | 불가(공식 경로 미확인) |
| 후루츠패밀리 | 공개 문서를 찾지 못함 | 검색 링크 | 불가(공식 경로 미확인) |
| 메루카리·Grailed·Vinted·Depop | 이번에 조사하지 않음 | 검색 링크 | 미확인 |

- "찾지 못함"은 "없다"의 증명이 아니다. 검색에서 나온 것은 제3자가 만든 수집 도구(Apify 등)뿐이었고, 각 회사의 개발자 문서·제휴 안내는 나오지 않았다.
- 제3자 수집 도구나 화면 긁어 오기는 쓰지 않는다. 공식 경로가 아니고, 대표의 기존 원칙(사이트 차단을 우회하는 대리 접속 금지)과 각 사이트 약관에 걸릴 수 있다. 각 사이트 약관의 자동 수집 조항 원문은 이번에 확인하지 못했다.

## eBay를 쓰려면 (대표 승인 필요)

- 필요한 것: eBay 개발자 계정, eBay Partner Network(EPN) 가입, 사업 모델 심사 통과. 새 계정·제휴 가입이라 **대표 승인 경계**에 해당한다.
- 문서에 적힌 조건(2026-11-15 확인): 운영 사용은 파트너만, 승인 보장 없음, 제휴 추적 구현 또는 샌드박스 검토, 기본 결과는 즉시구매(FIXED_PRICE) 상품, 배송비 따로 표시, eBay 로고·판매자 이름 표시.
- 문서가 알림·자료 저장을 허용하는지는 읽은 2쪽에 없었다. API License Agreement를 따로 확인해야 한다.
- 한계: 해외 배송·관세·영어 검색어. 대표가 원한 "당근 같은 국내 중고"의 대체는 아니다.

## 추천 순서

1. **지금 방식 유지 + 다시 찾기를 쉽게**(새 비용·계정 없음): 적어 둔 옷을 첫 화면에서 한 번에 다시 찾게 한다. 11-15에 오늘 탭에 「찾는 중」 바로 가기를 넣었다.
2. **국내 판매처에 제휴·API 문의**(대표가 보낼 메일 초안은 Claude가 쓸 수 있음): 당근·번개장터·후루츠패밀리에 "검색 결과 연결 또는 새 매물 알림을 공식으로 받을 방법"을 묻는다. 답이 오기 전에는 만들지 않는다.
3. **eBay 파트너 신청**: 해외 빈티지를 찾는 사용자가 실제로 있는지 본 뒤에. 승인 절차가 길고 국내 수요와 거리가 있다.

각 판매처 앱의 **자체 키워드 알림**(당근·번개장터 앱 안의 기능)은 사용자가 직접 켤 수 있다. 행잇이 "이 검색어로 당근 알림을 켜 두세요"라고 안내하는 것은 새 권한 없이 가능하다 — 다만 각 앱에 그 기능이 지금 어떤 이름으로 있는지는 이번에 확인하지 않았다.
