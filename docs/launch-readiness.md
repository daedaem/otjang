# 실제 서비스 준비 점검표

작성: 2026-11-14, Claude. 대표가 "실제 서비스 할 거에요"(11-12)라고 했고, 개편 A 7단계로 정리했다. **이 표는 승인이 아니다.** 각 줄의 "결정"은 대표만 할 수 있고, 공개 배포·새 비용·계정/권한 확대·사진 외부 전송은 줄마다 따로 승인받는다. 근거가 이 저장소 문서에 있는 것만 적었고, 확인하지 않은 것은 "미확인"으로 둔다.

## 대표 휴대폰 확인 목록 (각 1분)

1. 앱을 열면 「오늘」 탭에 오늘 코디가 옷걸이 봉에 걸려 보이는지, 아래 탭이 오늘·옷장·찾기·둘러보기·나 다섯 개인지.
2. 옷장 탭의 「스타일 목표」에서 목표를 바꾸면 빈자리 지도와 「먼저 채우면 좋은 옷」이 바뀌는지.
3. 상품을 열면 「살까 말까」 → 「이 옷을 넣으면」 → 「어디서 살까」 순서인지, 당근·번개장터 링크가 열리는지.
4. 찾기 탭 「찾는 중」에 본 옷을 적어 두고 다시 열었을 때 남아 있는지.
5. 긴 상담 답변과 입력 중 키보드에 화면이 가리거나 튀지 않는지(11-01 다기기 대응).
6. 마음에 안 들면 나 → 설정 → 「이전 화면으로 보기」로 돌아갈 수 있는지.
