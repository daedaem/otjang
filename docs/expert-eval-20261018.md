**② 이해 못 한 요청에 대체 상품을 보여 주는 것은 좋은가** (그로스 PM: "막다른 화면이 없어서 좋다" / 무신사 PM, 지그재그 PD, UX 리서처: "관계없는 16개는 실패를 숨긴다")

**③ 옷장이 비었을 때 상품 시트의 주 버튼은 '비교'인가 '구매 링크'인가** (서비스 정의의 흐름 '내 옷과 비교 → 결정' / UX 리서처, 그로스 PM: "사진부터 올리라니 이탈한다")
