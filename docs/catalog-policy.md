# 검증 카탈로그 정책 · 2026-10-13

`app/data/picks.json`(추천에 쓰는 상품 목록)을 무엇으로, 어떻게 채우고 고치는지 적은 문서다. 코드는 이 정책을 시험으로 지킨다(`app/test/pick.test.cjs`, `app/test/recheck.test.cjs`, `app/tools/validate-catalog.mjs`).

## 1. 넣는 상품

- **출처**: 브랜드 공식몰, 또는 브랜드가 직접 입점한 큰 몰의 브랜드관(예: 코오롱몰 포터리 브랜드관). 사람이 상품 페이지를 직접 열어 확인한 값만 넣는다.
- **넣지 않는 곳**: robots.txt 로 자동 수집을 막은 곳(무신사 `User-agent: *` 전면 금지, 2026-10-12 확인)은 열어서 값을 옮기지 않는다. 사용자가 그곳에서 보던 상품은 앱의 "보던 흰 티가 있나요?"에 **사용자가 직접 적어** 견줄 수 있고, 그 값은 카탈로그에 들어가지 않는다(이 브라우저에만 남는다).
- **품목 기준(흰 크루넥 티)**: 흰색 크루넥 티셔츠, 국내에서 주문할 수 있고, 가격·소재가 페이지에 적혀 있을 것. 해외 공식몰(브론슨)은 배송비 안내가 있을 때 넣고, 관세·부가세는 따로 확인하라고 적는다.
- **우선 확인**: 사용자가 좋아한다고 한 브랜드(폴로·브론슨·포터리·아웃스탠딩·브룩스 브라더스·LVC)를 먼저 찾는다. 찾지 못하면 그 이유를 `brandNotes` 에 적어 화면에서 알린다(지어내서 채우지 않는다).

## 2. 값과 출처 등급

| 등급 | 뜻 | 품질 근거 가중 | 조건 판정 |
|---|---|---|---|
| 공식(official) | 공식몰 상세 문구, 공식 치수표 | 1 | 확인 ✓ |
| 상품정보제공고시(notice) | 법정 표기(혼용률·제조국) | 1 | 확인 ✓ |
| 공식 원단 무게로 판단(official-weight) | 공식 원단 무게(예: 10.5oz)로 두께를 판단 | 1 | 확인 ✓ |
| 상품 사진으로 본 판단(photo) | 로고 위치·목 립처럼 눈으로 볼 수 있는 것만 | 0.6 | 로고는 확인, 그 밖은 약한 확인 ◐ |
| 상품명에만(name) | 이름에만 있는 말(예: "수피마") | 0.5 | 약한 확인 ◐ |
| 판매처 설명(seller) | 판매처가 쓴 설명. 자동 생성일 수 있다 | 0.3 | 약한 확인 ◐ |
| 직접 입력(user) | 사용자가 '지금 보는 상품'에 적은 값. **카탈로그에는 쓸 수 없다** | 0.5 | 확인 ✓(본인 판단) |

- 판매처가 "AI로 자동 추출한 정보"라고 밝힌 치수표(코오롱몰)는 그 사실을 `sizeNote` 에 적는다.
- 페이지에 없는 값은 비워 두고 화면에 "모름(?)"으로 보인다. 다른 상품에서 짐작해 채우지 않는다.
- 상품 사진·리뷰 문장은 가져오지 않는다(저작권). 화면의 티셔츠 그림은 공개된 값으로 그린 모양이다.
- 가격은 쿠폰을 받기 전 값이다. 쿠폰가가 페이지에 보이면 `priceNote` 에 날짜와 함께 적는다. 배송비는 한 번에 그 상품만 주문할 때 기준으로 "지금 낼 돈"에 더한다.

## 3. 갱신

- **운영자가 실행할 때만** 다시 본다(자동 수집·예약 실행 없음): `npm run recheck -- plan` 으로 볼 목록을 뽑고, `fetch` 는 robots.txt 를 지키며 판매처당 10초에 1건, 한 번에 30쪽까지 가격·재고만 읽는다. 브라우저로 직접 본 값도 같은 관측 형식으로 적어 `apply` 한다. 소재·치수·설명은 사람이 상세를 다시 볼 때만 고친다.
- 제안 주기: 7일마다. 확인한 지 14일이 지나면 화면에 "다시 확인 필요"가 붙고, 30일이 지나면 그 상품은 추천에서 빠지며 검사기가 오류([만료])로 빌드를 멈춘다(개발 중에만 `ALLOW_STALE=1`).
- 점수는 날짜 때문에 바뀌지 않는다(오래된 가격을 이유로 말하지 않을 뿐). 날짜가 지나도 1등이 바뀌지 않는 것은 시험으로 확인한다.

## 4. 순위의 중립성

- 순위는 사용자가 고른 기준과 공개된 값으로만 계산한다. **광고비·입점비·제휴 수수료는 계산에 쓰지 않는다.** 상품에 그런 값을 붙여도 순위가 같다는 것을 시험으로 확인한다(정리 단계에서 그런 값은 아예 버린다).
- 제휴 링크를 쓰게 되면 그 사실을 링크 옆과 추천 화면 첫 부분에 밝히고, 이 문서와 시험을 먼저 고친다.
- 1등·대안은 어울이 확인한 상품 안에서만 고른다. 사용자가 직접 넣은 상품은 "몇 위인지"만 알려 준다.

## 5. 정정

- 틀린 값을 찾으면 근거 주소와 확인일을 함께 고치고 커밋 메시지에 남긴다. 화면에는 늘 마지막 확인일이 보인다.
- 평가·사용자 의견으로 의심이 생긴 값(예: 두 상품의 치수표가 똑같음)은 검사기 주의로 남기고, 판매처 페이지를 다시 본 결과를 `sizeNote` 등에 적는다.
