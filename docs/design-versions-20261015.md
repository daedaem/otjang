# 디자인 시안: 같은 앱, 다른 이름·모습 (2026-10-15)

## 왜 만들었나

서비스 이름과 디자인을 정하기 전에, 그림(목업)이 아니라 **실제로 작동하는 앱**을 휴대폰에서 나란히 비교하기 위해서다.
시안은 기능·데이터·추천 엔진이 모두 같다. 이름·글꼴·색·재질과, 시안이 켜는 화면 장치만 다르다.

## 지나온 판단

1차 시안 넷(들임·가늠·딱·매무새) 중 **딱**만 남겼다. 나머지 셋은 같은 화면에 색과 글꼴만 바꾼 정도여서 차이가 약했다.
딱이 살아남은 이유는 색이 아니라 "딱!" 도장 한 번이라는 순간과 말투였다. 그래서 2차는 이름을 딱으로 두고 다음 두 가지를 했다.

1. 도장을 앱 전체 경험으로 키웠다.
2. 분위기가 완전히 다른 넷을 만들었다.

## 딱 v2 공통 장치 (`BRAND` 설정으로 켜고, 기본 빌드에서는 모두 꺼져 있다)

| 설정 | 화면 |
| --- | --- |
| `stamps` | 판정 도장. 상품 화면과 구매 기록에 붙는다. 결정 버튼은 "딱! 사기로 할게요 / 잠깐 보류할게요 / 패스 안 살게요"로 바뀐다. 구매 여정 위에는 **도장 수첩**이 생긴다(딱·잠깐·패스 개수, 패스한 옷의 기록 가격 합계). |
| `deck` | 홈 첫 화면이 **오늘의 판정**이 된다. 후보 한 벌과 도장을 보여 주고, "다음"을 누르면 다음 후보로 넘어간다. 후보 순서는 한 벌 빈자리 → 두 벌 조합 → 추천 상품이다. |
| `wardrobe` | 옷장 탭이 **옷장 속**이 된다. 상의·아우터·원피스는 봉에 걸고, 하의는 선반에 개어 두고, 신발은 바닥에, 소품은 서랍에 둔다. 옷장 탭에 들어올 때마다 문이 한 번 열린다. 검색·필터·확인 필요 보기를 쓰면 기존 목록으로 돌아간다. |
| `daypart` | 문서 루트에 `data-daypart`(dawn·day·dusk·night)를 단다. 시간대에 따라 조명이 바뀌는 시안에 쓴다. |
| `haptic` | 결정을 찍을 때 짧게 진동한다(지원하는 브라우저만, iPhone Safari는 지원하지 않는다). |

도장은 비교 결과를 다시 보여 줄 뿐, 새 판단을 만들지 않는다.

- **딱!**: 코디가 1개 이상 되고, 겹치는 옷(같은 상품·비슷한 옷)이 없을 때.
- **잠깐**: 그 밖의 모든 경우.

예시 옷장으로 둘러볼 때는 "예시 옷장 기준"이라고 표시한다. 도장 수첩의 금액은 절약액이 아니다. 패스한 후보를 기록할 때의 가격을 더한 값이다.

## 만드는 법

```bash
node app/tools/build.mjs --theme ttak-bojagi                                    # dist/index.html이 조각보 시안이 된다
node app/tools/build.mjs --fragment --theme ttak-room --out /tmp/room.html      # 페이지 뼈대를 씌워 주는 호스팅용
```

- `app/src/brand.js`: 기본 빌드의 이름·문구와 위 설정(모두 꺼짐).
- `app/themes/<id>.json`: 시안의 `brand`, `include`(먼저 붙일 공통 CSS), `themeColor`(브라우저 상단 색), `fonts`(Google Fonts 주소).
- `app/themes/stamp-base.css`: 딱 시안 공통 뼈대(판정대, 도장, 도장 수첩, 옷장 속, 문). 재질은 각 시안 CSS가 덮어쓴다.
- `app/themes/<id>.css`: 시안의 색·글꼴·재질.

## 지켜야 할 것

- 기본 빌드(`--theme` 없음)는 바뀌지 않는다. `app/test/theme-build.test.mjs`가 다음을 확인한다.
  - 기본 빌드에는 시안 CSS·글꼴 링크·판정대·옷장 속·도장 수첩이 없다.
  - 각 시안에는 이름·글꼴·상단 색이 들어가고, 판정 도장·판정대·옷장 문(한 번만)·도장 수첩·구매 기록 도장이 그려진다.
- 시안의 글꼴은 Google Fonts에서 받는다. 운영 서버 빌드에 쓰기로 하면 글꼴 파일을 직접 두는 쪽(외부 요청 없음)을 다시 정해야 한다.
- 시안별 링크는 저장소가 서로 달라서, 한 링크에서 등록한 옷은 다른 링크에 보이지 않는다.
- 기울인 카드와 도장이 화면 폭을 넘겨 휴대폰 화면이 축소되지 않도록 `.app`에 `overflow-x: clip`을 둔다.

## 정할 것

1. 분위기: 넷 중 하나, 또는 섞기(예: 드레스룸 옷장 + 조각보 낙관).
2. 이름: 딱으로 갈지. 한 글자 흔한 부사라 검색에서 묻히거나 상표 식별력이 약할 수 있다(추론, KIPRIS 확인 필요).
3. 고른 뒤에는 기본 `styles.css`·`brand.js`로 합치고, 나머지 시안 파일은 지우거나 비교용으로 남긴다.
