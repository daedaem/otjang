## 전체 React 전환 2026-10-25 확정

대표가 검토 채팅에서 전체 전환을 확정했고 이 ‘어울 개발’로 구현을 위임했다. #74를 먼저 마무리한다. 현재는 직접 입력만 React이며 전체 전환 완료가 아니다. 한 영역 한 담당 규칙을 적용하고 다른 채팅에서 중복 구현하지 않는다.

1. 시작 전 기존 Node/브라우저 검사를 실제 사용자 흐름에 대응시킨다. 홈→검색→결과, 상담, 날씨, 주문→수령→보유→반품에서 없는 행동 검사만 보충한다.
2. 기본 분할 후보는 상품 검색 등록 → 옷장 → 상세/판단 → 구매 기록 → 상담 → 백업이다. 홈·공통 호스트·날씨 의존성을 먼저 조사해 순서를 바꿔야 하면 근거를 남긴다. 화면별 작은 PR로 비교하며 거대한 단일 React 컴포넌트로 옮기지 않는다.
3. 순수 화면 전환은 저장 키/스키마·원자 command·멱등성·초안·백업을 유지한다. 대표가 후속 승인한 R22 B1의 속성 확장은 별도 호환 버전·이전 PR로 다루며 기존1/미래 보호·원문·재시도·복원을 증명한다. 전환 전후 같은 행동 검사를 실행하고 실제 종류·색·ID·구매 단계·새로고침 후 값을 대조한다. 저장 건수만 같은 것으로 통과시키지 않는다.
4. 같은 합성 자료·화면 크기·상태로 전후 화면을 비교한다. 초점·키보드·뒤로가기·애니메이션은 별도 행동으로 확인한다. 임의 서비스/디자인 방향 변경은 포함하지 않는다.
5. 전체 흐름, 자료 보존/복구, 실제 iPhone/Galaxy 확인 전까지 바닐라 화면 및 `?input=vanilla` 복귀 경로를 제거하지 않는다. 첫 화면 구현·검사·리뷰의 실제 소요를 측정한 뒤 남은 일정을 산정한다. 과거15~25인일은 확정 일정이 아니다.

#74의 최종 CI·검토 확인은 아래 첫 전환 PR보다 우선한다. 이 문서의 전환 결정은 새로운 운영 배포 승인이 아니다.
