# 살까말까(salmal) 목업 (2026-10-19)

> 문서 시점: 2026-10-19. 당시의 검토·구현 기록을 보존한 자료입니다. 현재 결정·우선순위·운영 상태는 [최신 문서 목차](README.md)를 확인합니다. 아래의 “지금·완료·다음”은 별도 갱신 표시가 없으면 당시 기준입니다.

대표 요청: 기존 어울은 그대로 두고, "살까말까" 버전을 실제 눌러 볼 수 있는 별도 모바일 목업으로. 이름만 바꾸지 않고 salmal에 맞는 화면·문구·디자인은 Claude가 판단.

- 파일: `app/mockups/salmal/index.html` (독립 HTML 한 파일, 외부 요청 0, 글꼴도 기기 글꼴). 어떤 정적 서버에서나 열린다. 기존 앱·DB·`app/proto` 빌드와 무관하다.
- 원스톱 정의 유지: 옷장 없이 요청 → 실제 상품 후보 → 내 옷과 비교 → 살까·말까 → 기록(주문·받음·입음·반품).

## 설계 판단 (어울·살까 시안과 다른 점)
| 항목 | 판단 |
|---|---|
| 화면의 단위 | "질문 한 줄 → 답 한 단어". 후보 카드마다 **살까 / 보류 / 말까** 도장이 먼저 보이고, 그 아래 한 줄 이유, 그 다음 상품 정보. 어울은 상품이 먼저고 판정은 상세 안에 있다 |
| 말까를 숨기지 않음 | 겹침(같은 종류·같은 색), 이미 산 옷, 반품 기록은 **말까·보류**로 바로 나온다. "살까" 시안(토스풍, 10-15)은 긍정 문장 중심이었다 |
| 옷장 없을 때 | 도장이 "조건 맞음"(회색)이다. 옷장 없이도 답이 나오지만 겹침은 못 봤다고 쓴다. 상세에서 "예시 옷 3벌 켜고 다시 보기"로 차이를 바로 보여 준다 |
| 결정은 사람이 | 판정은 참고. "사기로 함·보류·안 살래"를 직접 누르고, 판정과 같은 버튼만 테두리로 기울여 둔다 |
| 기록이 다음 답을 바꿈 | 계속 입기로 한 옷은 내 옷에 들어가 같은 상품이 "이미 산 옷"으로, 같은 종류·색이 "말까"로 바뀐다. 반품은 같은 브랜드·종류에 경고 태그로 돌아온다 |
| 디자인 | 종이색 바탕·검정 잉크, 도장 3색(초록·황토·적갈). 사진 없이 색 견본 블록. 토스 파랑(살까 시안)과 어울의 톤과 구분된다 |

## 진짜인 것 / 가짜인 것
- 진짜: 상품 이름·브랜드·가격·링크·추천 이유는 어울 엔진 `search()`로 2026-10-19에 뽑은 실제 수집 상품(무신사, 10월 13일 수집가) 13개. 가격은 "수집가"로만 표기, 현재가·최저가라고 쓰지 않는다.
- 가짜(목업): 요청 해석은 예시 4문장 고정(다른 말은 "이 목업은 그 말을 몰라요"). 판정은 목업 규칙(겹침·같은 색·상황 불일치·반품 기록·성별 불일치)이며 본 앱의 `compareCandidate`(코디 공식 수까지 봄)와 다르다. 코디·가상 착용·실시간 가격 없음.
- 없는 것: 사진, 계정, 저장(메모리뿐, 새로고침하면 초기화), 외부 전송. 상품 사진은 권리 미확인이라 뺐다. 상단 띠와 "이게 뭐예요?" 시트에 목업임을 밝힌다.

## 확인 (클라우드 Chromium 390×844)
묻기 → 답(옷장 없음, "조건 맞음") → 상세 → 예시 옷 켜기("말까", 흰 옥스퍼드 겹침) → 답(말까/보류/보류/보류) → 사기로 함 → 기록(주문→받음→계속 입음) → 같은 요청에서 그 상품이 "이미 산 옷" → 두 번째 상품 반품(사유 시트) → 같은 브랜드·종류에 "반품 기록 있음" → 모르는 문장 안내 → 여성 원피스는 남성 예시 옷장과 "비교 못 함". 가로 넘침 없음(scrollWidth 390).
