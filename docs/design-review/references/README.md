# 공개 3D 참고작 출처

2026-10-11, 한국 시간. 아래 파일은 제작자 공개 저장소가 제공한 **원본 썸네일**이다. 이 프로젝트의 결과물이나 이번 조사에서 직접 촬영한 라이브 화면이 아니다. 원본 파일을 변경하지 않고 복사했다. 화면을 직접 보고 관련 코드를 읽었으며, 라이브 사이트 실행·모바일 성능·수상 이력은 검증하지 않았다.

Room 모델: **“Room” by Anex**, [원 모델](https://sketchfab.com/3d-models/room-6417cbc1870a4a1691cca06912ae0369), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 위 `Room.tsx`의 제작자·모델명·라이선스 표기를 직접 확인했다. 원 모델 사이트 자체는 방문하지 않았다. 모델과 썸네일을 이번 프로젝트가 제작한 것으로 소개하지 않는다.

이미지는 시각 품질 비교·비평을 위한 참고 자료로만 보관한다. 제품의 실제 의류·실내 자산으로 가져오지 않았다. 비교 보드에서도 각 이미지의 제작자와 자료 성격을 표시한다.
