# 결정 기록 001 — 개인판을 먼저 완성한다

- 날짜: 2026-10-11, 한국 시간
- 상태: 사용자 결정 일부 확정, 세부 제안 검토 중
- 연결: [PRD v0.4](../PRD-v0.4.md)

## 사용자 결정

이번 대화에서 사업 아이디어와 이직 포트폴리오를 함께 추구하고, GitHub에 협업 과정을 남기며, 구현 전에 PRD를 정리하기로 했다. 첫 범위는 본인 전용으로 충분히 완성한 뒤 공개 여부를 결정하는 것이다.

사용자가 구체화한 고민은 원하는 스타일로 옷장을 채워 가면서, 보유 옷과 활용도가 높고 체형·얼굴 분위기에 맞는 아이템을 찾는 것이다. 커뮤니티 추천, 후기 검색, 판매처 재검색에 흩어진 과정을 본인에게 맞게 한곳에서 해결하고 싶다는 요구다. 따라서 내 옷 코디와 후보 판정뿐 아니라 보완할 아이템 제안·실제 상품 발견·관련 후기·구매처 연결을 제품의 중심에 둔다.

커뮤니티가 사업 성장에 중요할 수 있다는 사용자 의견은 검토할 가설이다. 더 나은 대안을 검토할 수 있으며, 지금 공개 커뮤니티를 만들기로 결정한 것은 아니다.

## 검토한 전략

1. **개인화된 원스톱 옷장 보완 먼저, 기록을 기반으로 커뮤니티 확장 — 추천.** 현재 선택한 본인 전용 범위와 맞고, 공개 전에도 쓰는 이유가 있다. 다만 상품·후기 자료 확보와 개인화 품질이 검증되어야 하며, 기록 공유만으로 유입이 생길지도 미검증이다.
2. **패션 커뮤니티부터 출시.** 교류가 생기면 가치가 커질 수 있지만, 초기 콘텐츠·기여자·운영 부담이 크고 이번 사용자의 출시 순서와 맞지 않는다.
3. **실사/3D 미리보기부터 출시.** 시각적 경험을 직접 검증할 수 있지만 표현 품질과 비용 문제가 전체 제품을 지연시킬 수 있다. 별도 품질 실험으로 유지하는 것을 추천한다.

추천안은 시장 조사로 입증된 우위가 아니라 현재 요구와 제약에 따른 판단이다. 개인 사용을 마친 뒤 공개 여부를 결정할 때 다시 검토한다.

## 결정의 효과

- 기능 개발과 추가 렌더 작업보다 PRD와 화면 흐름 정리를 앞세운다.
- 사업 지표와 개인 도구의 만족도, 기술 포트폴리오 증거를 분리한다.
- 구현 범위를 줄이더라도 실제 상품 추천·실사 착장이라는 장기 요구를 삭제하지 않는다.
- PRD v0.1과 원본 인계 자료는 로컬 보존한다. 공개 GitHub에는 선별한 현재 문서와 검증 근거를 기록한다.

## 작업명 변경

사용자가 기존 이름을 바꾸도록 요청했다. 현재 기획 작업명은 **웨어넥스트(WearNext)**로 변경한다. ‘나에게 맞는 다음 한 벌’이라는 목적을 담은 Codex 제안이며, 최종 브랜드명과 상표·도메인 사용 가능성은 확정하지 않았다. 기존 인계 자료와 소스의 역사적 명칭은 보존한다.

## 아직 합의하지 않은 것

PRD의 구체적인 수용 기준, 개인 사용 횟수와 통과 기준, 첫 상품 탐색 범위, 수동 큐레이션 방식, 얼굴 분위기·체형 반영 방법, 판매처 결제로 연결하는 초기 원스톱 경계, 화면 표현, 서버 착수 시점은 Codex 제안이다. 사용자 리뷰 전까지 확정으로 표시하지 않는다.
