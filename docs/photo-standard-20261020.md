# 사진 기준 (2026-10-20, 초안)

수상작 학습(`docs/design-study-awards-20261020.md`)에서 가장 먼저 지킬 원칙은 **"모든 물건을 한 배경, 한 비율로 맞춘다"**였다. 지금 시안이 싸 보이는 가장 큰 원인은 화면이 아니라 사진 자료다. 아래는 화면과 자료에 함께 적용할 기준이다.

## 1. 화면 규칙

| 쓰는 곳 | 사진 | 처리 |
|---|---|---|
| 내 옷장 칸, 조합 콜라주, '기본 옷' 칸 | 흰 배경 단독 상품 사진만 쓴다(종류·색이 같은 비슷한 상품 사진) | 3:4 회색 칸 가운데, 칸 높이의 약 78%, 곱하기 합성으로 흰 배경을 칸 색에 녹인다 |
| 위 칸에서 흰 배경 사진이 없을 때 | 모델 사진을 섞지 **않는다** | 색 칸 + 종류 이름으로 둔다 |
| 검색 결과·상품 상세 | 판매처 사진 그대로 | 흰 배경 사진은 위와 같이, 모델·연출 사진은 같은 3:4 칸을 꽉 채운다(자르기). 칸 크기·비율은 같다 |
| 금지 | 밝기 올리기 필터 | 흰 옷(흰 운동화·흰 티셔츠)까지 지워진다(매거진 시안에서 확인) |

- 흰 배경 판정 목록: `app/mockups/ux10v2/links/shared/photo-kinds.js`(891장 중 369장이 흰 배경 단독 사진).
- 판정 방법: 사진 가장자리 픽셀의 평균 밝기(RGB 최솟값 238 초과)와 고르기(분산 150 미만), 물건이 차지하는 비율(6~88%)로 판정했다. 사람이 찍힌 5장은 손으로 뺐다. 자동 판정이라 틀린 사진이 있을 수 있다.

## 2. 자료 규칙 (카탈로그를 다시 모을 때)

지금 검색 예시 결과 157개 중 흰 배경 단독 사진은 36개(23%)뿐이다. 나머지는 모델 사진이라, 화면 규칙만으로는 톤이 다 맞지 않는다.

1. 상품을 모을 때 대표 사진과 함께 **흰 배경 단독 사진(누끼컷)이 있으면 그 주소도 모은다.** 판매처 상세 페이지에는 보통 여러 장이 있다. 어느 사진을 쓸 수 있는지는 판매처 이용 조건과 제휴 조건을 먼저 확인해야 한다(사진 사용 권리는 아직 확인하지 않았다).
2. 카탈로그에 `photoKind`(flat / model / scene)를 기록해 화면이 추측하지 않게 한다.
3. 흰 무지 티셔츠처럼 흰 배경 사진이 없는 기본 옷은 기본 옷 목록에서 우선 수집 대상으로 둔다.
4. 사용자가 올린 내 옷 사진은 앱에 있는 배경 지우기(U-2-Netp, PR #17)로 같은 회색 칸에 넣는다.

## 3. 아직 모르는 것

- 판매처 사진을 서비스 화면에 써도 되는지(권리·제휴 조건): 확인하지 않았다.
- 흰 배경 판정의 정확도: 사람이 전수 확인하지 않았다.
