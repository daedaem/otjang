## 제안 (합의 전)

- 미확인(사진 초안) 속성도 판정·코디에 쓰되 결과에 "확인 전 속성 포함"을 표시하고, 자동으로 확인 상태로 올리지 않는다. v0.4가 이 방식이다.
- 개발 순서: M0 재현 → M1 스키마 2 → M2 등록 단계 → M3 3D 탭 → M4 상품 목록 (여기까지 완료) → M5 서버(시작 전 사용자 확인) → 실사 착장은 GPU·비용 확인 전 보류.
- 상품 사진의 세 상태(확인된 동일 제품 / 미확인 후보 / 대체 이미지)와 "종류로 그린 모습은 상품 재현이 아니다"를 화면 문구로 유지한다.

## 미검증 가설

- 사용자가 살까 말까 판정을 실제로 쓰고 결정에 도움이 된다(PRD 0단계 문턱: 실제 판정 3건, 현재 0건).
- 종류로 그린 3D 옷이 "내 옷을 걸어 둔 느낌"을 준다. 사용자 평가는 흔들림 시험("오 괜찮은데요?")까지이며 v0.4 통합 화면의 평가는 아직 없다.
- 직접 넣는 상품 목록만으로 구매 판단에 충분하다(상품 사진·가격을 0원으로 얻는 길은 조사 전).

## 알려진 한계

- 3D 형태는 셔츠·블레이저·필드 재킷·트러커 재킷 4종. 바지·신발·니트·블루종·스웻셔츠는 "3D 형태 없음"으로만 보인다. 옷장 자리 6곳.
- 3D 자산의 보이는 결함(옆 이음매 어두운 줄, 필드 재킷 옆판·주머니, 겨드랑이 밝은 점, 블레이저 뒷깃, 조명에 따른 색 변화)은 사용자 결정으로 미뤘다. 목록은 `blender/README.md`.
- 가격·재고·링크를 찾아오지 않는다. 어울림을 확률로 말하지 않는다. 핏과 소재는 판단하지 않는다.
- 파일 약 9MB. 저장은 브라우저 IndexedDB(없으면 localStorage)라 다른 PC와 동기화되지 않는다.
