# 대표 요구사항 (Claude·Codex 공통, 살아 있는 문서)

**이 문서가 대표 요구사항의 한 곳이다.** Claude와 Codex는 작업 전에 이 문서를 읽고, 대표가 새 요구·결정을 말하면 그 작업과 같은 커밋에서 여기에 적는다(날짜·출처 포함). 지난 항목은 지우지 않고 "바뀜/철회"로 표시한다. 자세한 근거는 각 줄의 문서 링크에 둔다.

마지막 갱신: 2026-10-21 (Claude, 브랜치 `claude/fashn-vton-m1-test-3ox240`)

## 1. 서비스 정의

- **한 줄:** 대충 말해도 나에게 맞는 실제 옷을 골라 주고, 옷장 비교 → 새 상품·중고 구매 → 구매 후 기록까지 잇는 원스톱 패션 서비스. 옷장 등록은 선택이다.
- **전체 목표**(2026-10-14, [제품 계약](onestop-product-contract-20261014.md)): 가진 옷에서 출발해 부족 발견, 취향·커뮤니티 탐색, 조합·가상 착용, 정확한 상품·옵션·가격 비교, 구매와 구매 후 관리를 잇는다. 같은 정보를 다시 입력하지 않게 하고, 결과가 다음 옷장·추천으로 돌아오게 한다. Acloset보다 나은 고객 경험이어야 한다.
- **서비스 이름:** 미정(화면에는 "이름 미정"). "어울"은 상표 때문에 쓰지 않는다. TACT는 35류 선출원 심사 중이라 미확정. 제안한 후보(제짝·옷깃·PEG)는 대표 선택 대기. **대표 제안(10-21): "Cho'ice"**(성 Cho + choice). 상표 검색(KIPRIS, 25·35·9·42류) 전 미확정. Claude 의견: 일반 단어라 상표 식별력이 약하고 말·검색에서 '가 사라짐 → 'ChoPick(초픽)'처럼 만든 말도 함께 검토.

## 4. 고정 원칙 (어기지 않는다)

- 사진(개인 옷장 사진)은 외부로 보내지 않는다. 받는 것은 코드와 가중치뿐. 온라인 데모·유료 API에 사진을 보내지 않는다.
- 계정 생성·결제·비용 발생은 대표가 직접 한다. 비밀 키·개인 사진은 저장소·공개 PR·채팅에 두지 않는다(키는 Cloudflare 비밀 값으로).
- 상품 사진은 사용 권리 미확인 → 링크를 외부에 공유하지 않는다. 공개 포트폴리오에는 화면 녹화를 쓴다.
- 가격은 늘 "수집가"(수집일 가격)로 표시. 중고는 "외부 검색 · 매물 확인 안 함". 모르는 속성·재고·중고 가격은 만들지 않는다.
- 체험용 옷은 가진 옷이 아니다(표시한다).
- "세계 최고 수준 달성", "사람 수상 디자이너 참여", "인간 전문가 투표"라고 말하지 않는다. AI가 역할을 맡아 만든 시안이다.
- 무단 수집(크롤링)으로 상품·매물을 가져오지 않는다.
