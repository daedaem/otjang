# 탭·옷걸이 띠·알림·저장소 안내 React 이전 (WO-08b)

이 작업은 WO-08a(공통 시트)를 바탕으로 한다. 담당은 Claude 패션(Opus 5.5), 브랜치는 `claude/wo-08b-chrome-20261027`이다. 범위는 화면 위아래에 늘 붙어 있는 공통 틀 네 가지다.

- 아래 탭 다섯 개
- 옷걸이 띠(걸어 본 옷이 있을 때 탭 위에 뜨는 줄)
- 잠깐 뜨는 알림(`K.toast`)
- 저장소를 읽지 못했을 때 남는 안내(`#eo-storage-issue`)

## 기준선 검사

기준선은 WO-08a에서 먼저 추가한 `e2e/common-ui.spec.ts`가 이미 고정했다. 탭 이동과 현재 탭 표시, 띠 요약과 옷장 열기, 알림 문구와 `role=status`, 읽을 수 없는 옷장의 안내(백업·원문 받기·두 단계 새로 시작)를 다룬다. 사진 백업 복구 대기 중 화면 잠금(`inert`)은 `photo-backup.spec.ts`가 다룬다.

## 무엇을 바꿨나

- **React 틀:** `src/chrome/AppChrome.tsx`(`EOUL_CHROME_LOAD` 섬의 `mountChrome`). 앱이 뜬 뒤 섬을 불러 바닐라 `#strip`·`#tabs` 자리에 같은 순서로 붙인다. 감싸는 요소는 `display: contents`라 배치와 초점 순서가 같다.
- **같은 모양:** 마크업·클래스·인라인 스타일·문구가 바닐라와 같다. 탭의 현재 표시(`aria-current`, 채운 아이콘), 띠의 `pop` 움직임, 알림의 들어오는 움직임과 2.6초 뒤 사라짐, 안내의 위치·색도 같다.
- **상태는 screen.html에 남긴다:** 지금 화면, 띠 요약, 저장소 안내 모델(`storageModel()`)과 명령(백업 열기·원문 받기·새로 시작)은 screen.html이 그대로 가진다. 바닐라 안내도 같은 모델로 그린다.
- **바로 그리기:** 상태가 바뀌면 React도 그 자리에서 바로 그린다(`flushSync`). 바닐라 코드가 `K.refresh()` 직후 `#strip`을 읽어 알림 위치를 정하기 때문이다.
- **안내는 부를 때마다 새로:** 안내는 `storageNotice()`를 부를 때마다 새로 만든다. 그래서 '새로 시작' 첫 누름 상태가 바닐라처럼 초기화된다. 원문도 그때 값으로 고정한다.
- **이중 처리 없음:** React 띠는 `data-tabgo`를 쓰지 않는다. 바닐라 탭에 붙였던 클릭 연결은 바닐라 요소와 함께 사라진다.
- **바닐라 경로:** `?ui=vanilla`이거나 섬을 불러오지 못하면 바닐라 탭·띠·알림·안내를 그대로 쓴다. 이 틀은 처음부터 바닐라로 보이기 때문에 실패 문구를 따로 띄우지 않는다.
