## 3. 있는 시안 검토 (화면 직접 확인)
### 03 비교함 — 가장 실서비스에 가깝다
- 잘된 점: 무신사형 2열 결과(사진 4:5, 브랜드→품명→가격+수집가), 카드마다 ‘비교 담기’, 비교 화면 2열 사진 + ‘내 옷과’ 첫 줄 + ‘같은 값 5줄’ 접기, 상세 하단 결정 바 3칸 같은 크기, PC 상세 왼쪽 큰 사진·오른쪽 정보.
- 고칠 점: P1 24px 미만 누르는 곳 1개(기록 화면에서 찾기). P1 상세 휴대폰 첫 화면에 판정이 안 보인다 → 가격 아래에 판정 한 줄 요약(`verdict.title`)을 올리고 자세한 비교는 아래로. P2 비교 화면 판정 문구가 빨강·파랑 글자색으로만 갈린다 → 아이콘이나 꼬리표를 더해 색에만 의존하지 않기. P2 ‘비교 담기’ 체크박스가 카드마다 반복돼 결과 밀도를 낮춘다 → 사진 위 작은 아이콘 버튼(44px 터치 영역)도 검토.
### 08 옷장 레일 — 개념이 가장 분명하다
- 잘된 점: 빈 옷장일 때 레일이 ‘비어 있어도 찾을 수 있어요 + 가진 옷 + 체험용 옷’ 한 줄, 넣은 뒤 레일에 ‘겹침 1’ 표시, PC 왼쪽 옷장 열이 겹침·코디 짝을 글자+테두리로 표시, 상세 ‘내 옷장과 나란히’가 후보 사진과 겹치는 옷 사진을 나란히.
- 고칠 점: P1 결과 카드 오른쪽 위 비교 아이콘(▯▯)에 글자가 없다 → aria-label 확인, 24px 미만 원인일 가능성. P1 PC 상세에서 ‘무신사에서 보기’가 검은 주 버튼이고 결정 버튼보다 강하다 → 어울의 주 행동은 판단·기록이므로 결정 버튼과 강조를 맞바꾸거나 같은 무게로. P2 비교 화면 하단에 탭바와 토스트가 겹친다 → 토스트는 탭바 위로.
### 09 읽는 결과 — 품질은 높지만 밀도가 낮다
- 잘된 점: 명조 제목·번호 01과 큰 사진의 잡지형 위계, ‘규칙으로 본 판정’ 상자로 사람 글처럼 보이지 않게 함, 상세 사실(수집가)과 판단 글자 구분, PC 상세 완성도 높음.
- 고칠 점: P1 결과 첫 화면에 상품이 1개(그것도 일부)만 보인다 → 제목·설명을 줄이고 01 사진을 화면 폭의 70%로 낮추거나 01~03 목차 띠를 첫 화면에 둬 3개 이상 보이게. P2 2~3개마다 소제목(약 12자) 규칙 확인. P2 결과에도 가격 기준(수집가) 한 줄이 첫 화면에 있는지 확인.

## 5. 참고 서비스와 같은 과업 비교 (남은 일)

## 6. 고르는 기준 (추천 순위를 낼 때)
점수는 같은 과업 결과로 낸다. 1) 실서비스 수준의 첫인상(사진 크기·밀도·위계, 참고 서비스 숫자와의 차이) 25% 2) 과업 성공과 오류 없음(조건 위반·복귀 오류·잘못된 기록 0) 25% 3) 옷장 없이 판단까지의 짧음과 옷장을 넣었을 때 판단의 분명함 20% 4) 신뢰(수집가·중고·체험용 표기가 짧고 정확) 15% 5) 접근성·작은 화면 15%.
현재 앱으로 옮길 때는 시안을 통째로 고르지 않고 조각을 옮긴다(1판 결론 유지: 답 카드, 결정 바 고정, 상세 안 옷 넣기 시트, 비교함 순).
