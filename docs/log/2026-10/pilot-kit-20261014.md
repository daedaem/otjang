# 파일럿 진행 자료 (5명, 1인당 약 20분)

> 문서 시점: 2026-10-14. 당시의 검토·구현 기록을 보존한 자료입니다. 현재 결정·우선순위·운영 상태는 [최신 문서 목차](../../README.md)를 확인합니다. 아래의 “지금·완료·다음”은 별도 갱신 표시가 없으면 당시 기준입니다.

목적은 `focus-plan-20261014.md`의 가설을 확인하는 것입니다. 가설은 "구매 직전 판단과 산 뒤 기록에서 어울을 다시 열 이유가 있는가"입니다. 판정 기준은 그 문서에 미리 고정해 두었습니다.

## 1. 모집 문구 (메신저에 그대로 붙여 넣기)

> 옷 사기 전에 "이거 살까 말까" 고민 많이 하시는 분 계세요? 제가 만들고 있는 옷 앱을 20분만 써 봐 주실 수 있을까요? 회원가입은 없고, 넣은 사진은 휴대폰 밖으로 나가지 않아요. 지금 사려고 고민 중인 옷이 하나 있으면 더 좋아요.

사례를 할지, 한다면 무엇으로 할지는 진행자가 정합니다. 앱 비용과는 별개입니다.

## 2. 대상 조건

- 최근 3개월 안에 온라인으로 옷을 산 적이 있는 사람
- 지금 사려고 고민 중인 상품이 하나 있는 사람. 없으면 기록하고, 다른 상품으로 바꿔 넣지 않습니다.
- 첫 대상은 아메리칸 클래식·아메카지 취향의 남성입니다. 다른 취향도 1~2명 섞어 경계를 확인합니다.
- 옷장 앱을 이미 쓰는 사람은 1명까지만 포함합니다. 비교용입니다.
- 지인 위주라 반응이 좋게 나오기 쉽습니다(편향). 기록에 그렇게 적습니다.

## 3. 시작 전 안내 (읽어 주기)

> 오늘은 앱을 평가하는 거지 ○○님을 평가하는 게 아니에요. 막히면 막힌 대로 말씀해 주시는 게 가장 도움이 돼요. 저는 화면을 보면서 메모만 하고, 사진이나 구매 내역은 따로 받지 않아요. 원하시면 언제든 그만두셔도 되고, 메모도 지워 드려요.

## 4. 진행 순서

1. **옷 3벌 넣기**: 참가자 휴대폰으로 실제 가진 옷 3벌을 넣습니다. 시간과 탭 수를 재고, 막힌 곳을 적습니다. 진행자는 돕지 않습니다. 도움이 필요하면 그 사실을 기록합니다.
2. **고민 중인 상품 판단**: 두 가지 방법으로 각각 판단하게 합니다.
   - 평소 쓰는 방법(무신사 앱, 사진 비교 등)
   - 어울에 상품 링크를 붙여 넣기
   - 두 방법의 순서는 참가자마다 번갈아 정합니다.
   - 각각 "산다 / 보류 / 안 산다"와 그 이유를 말하게 합니다.
3. **근거 확인**: 어울 판정 화면에서 무엇을 보고 판단했는지 손가락으로 가리키게 합니다.
4. **질문지** (아래 5문항)

## 5. 질문지

1. 어울을 쓰고 나서 구매 판단이 바뀌었거나 확신이 생겼나요? (바뀜 / 확신이 생김 / 변화 없음)
2. 어울이 보여 준 것 중 판단에 도움이 된 것은 무엇인가요? (가진 옷과 맞는 수 / 비슷한 옷 있음 / 완성되는 코디 / 가격 / 없음 / 기타)
3. 가장 답답했던 순간 하나는 언제였나요?
4. 다음에 온라인으로 옷을 살 때 무엇을 열겠어요? (어울 / 평소 방법 / 다른 앱: ____ )
5. 사진이 휴대폰 밖으로 나가지 않는 것이 중요한가요? (매우 / 조금 / 상관없음)
