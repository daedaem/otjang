# 공통 시트 React 이전 (WO-08a)

이 작업은 WO-07을 바탕으로 한다. 담당은 Claude 패션(Opus 5.5), 브랜치는 `claude/wo-08-common-20261027`이다. WO-08은 세 단계로 나눠 진행한다.

- **WO-08a(이번):** 공통 아래 시트
- **WO-08b:** 탭·옷걸이 띠·알림·저장소 안내
- **WO-08c:** 남은 옷 타일과 옷 정보 시트

## 기준선 검사 (먼저 추가)

공통 화면에는 전용 브라우저 검사가 없었다. 그래서 바닐라의 현재 동작을 `e2e/common-ui.spec.ts` 6개로 먼저 고정했다(`f1ae499`, 바닐라에서 통과).

- 아래 탭 다섯 개로 화면을 옮기고, 현재 탭을 표시한다.
- 옷을 걸면 옷걸이 띠가 나타나 요약을 보여 주고, 누르면 옷장이 열린다.
- 메뉴에서 설명을 열고, 밝게·어둡게를 바꾸고, 처음부터 다시 시작한다.
- 정보 버튼으로 설명을 열고, Escape로 닫는다.
- 종류·색으로 넣기는 종류 → 색 순서로 묻고, 알림으로 마무리한다.
- 읽을 수 없는 옷장은 알림을 남긴다. 알림에는 백업, 원문 받기, 두 단계 새로 시작이 있다.

## 무엇을 바꿨나

**React 시트:** `src/chrome/`(`EOUL_CHROME_LOAD` 섬). 아래 시트 여덟 가지를 React로 그린다. 문구와 클래스는 바닐라와 같다.

| 시트 | 바닐라 함수 |
|---|---|
| 메뉴 | `menu()` |
| 설명 | `disclose()` |
| 확인 | `confirmSheet()` (상담 지우기) |
| 색 고르기 | `pickColor()`, '가진 옷 있어요'(`answerOwn`), '가진 ○○ 걸기'(`addLike`) |
| 종류·색으로 넣기 | `addFlow()` |
| 반품 사유 | `returnSheet()` |
| 구매 판단 | `decisionSheet()` (바꾸기, 판매처에서 돌아왔을 때) |
| 날씨 지역 | `placeSheet()`, WO-02의 React 지역 대화상자를 재사용 |

**바닐라와 같게 유지한 것**

- **겉모양과 움직임:** 열고 닫는 움직임, Escape·배경 눌러 닫기, 시트 하나만 열리는 규칙(`.sheet` 확인)이 바닐라 `sheet()`와 같다.
- **상태 변경은 screen.html에 남긴다:** 코어 명령, 새로고침, 알림을 screen.html이 그대로 맡는다. 시트는 눌린 값만 돌려준다.
  - 순서도 바닐라와 같다. 먼저 기록하고, 시트를 닫은 다음, 이어지는 일을 한다.
  - 기록이 실패하면 시트를 닫지 않는다(반품 기록 실패 시 알림).
- **이중 처리 없음:** React 시트는 `document.body` 아래 따로 그린다. 시트의 `data-*` 속성은 전역 클릭 위임이 듣는 이름과 겹치지 않는다(`data-c`, `data-k`, `data-d`, `data-reason`, `data-ok` 등은 시트 안 전용).
- **바닐라 경로:** `?ui=vanilla`이거나 섬을 불러오지 못하면 기존 바닐라 시트를 그대로 연다.
