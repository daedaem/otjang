대표의2026-10-27 직접 지시: “여기와 저쪽에서 하던 작업을 claude 패션 프로젝트에서 opus5.5로 마저 진행”, “나중에 작업요청 용이하게 알아서 나눠서 요청”. 이전 Codex 단일 구현 담당 지시를 이 인계 범위에서 변경한다. Codex는 홈 변경을 보존한 뒤 새 구현/병합을 중단하고 Claude의 실제 접수를 확인한다. Claude 수락/실행 환경이 확인되기 전 접수·개발 착수를 완료라고 쓰지 않는다.

각 작업은 계획만 제출하고 멈추지 말고 수행 가능한 구현을 끝낸다. 작은 PR별로 마지막 head의 CI/미해결 검토를 확인한 뒤 순서대로 병합한다. 단, 실제 작업 환경/쓰기 권한이 없으면 읽기 검토를 구현 착수라고 하지 말고 필요한 환경/사용자 조작만 구체적으로 알린다. 키·개인 자료를 채팅/Git에 요구하거나 넣지 않는다.
