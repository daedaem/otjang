# 번호별 작업 요청 목록 (Claude → GPT/Codex 인계)

현재 담당: GPT/Codex 어울 개발(10-28 18:08 대표 이어받기 지시, master #119). 아래 10-27 Claude 이전 설명은 이력이다. 현재 작업 표와 개발 계획 첫 줄을 먼저 확인한다. [실제 수신·후속 검사](gpt-handoff-example-photos-20261028.md)를 남긴다.

대표의2026-10-27 직접 지시: “여기와 저쪽에서 하던 작업을 claude 패션 프로젝트에서 opus5.5로 마저 진행”, “나중에 작업요청 용이하게 알아서 나눠서 요청”. 이전 Codex 단일 구현 담당 지시를 이 인계 범위에서 변경한다. Codex는 홈 변경을 보존한 뒤 새 구현/병합을 중단하고 Claude의 실제 접수를 확인한다. Claude 수락/실행 환경이 확인되기 전 접수·개발 착수를 완료라고 쓰지 않는다.

대상은 Claude ‘패션’ 프로젝트의 기존 [React 대화](https://claude.ai/chat/e43aefa4-a283-4e4b-b0de-d98e32d5f8e6)다. 인계 시 UI에 Opus5.5 엑스트라가 선택된 것을 확인했다. 작업은 아래 번호로 요청하며 한 번에 한 영역/한 구현 담당만 둔다. 먼저 최신 master와 진행 표시·열린 PR을 읽는다. 선행 작업이 미완료면 그 작업부터 마친다.
