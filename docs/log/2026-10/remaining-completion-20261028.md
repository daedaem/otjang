## WO-11d를 이렇게 마친 이유

기존 v2의 옷장 도구는 정렬·브랜드·진열장·종류 등록이 사진 위에서 큰 줄을 차지했고, 결과 카드의 핵심 동작은 옷걸이 아이콘만 보였다. 이미 확정된 Daedaem 1.1.1·무채색/월넛/잎 초록 체계를 유지하면서 조작만 정돈했다.

- v2에서 **옷장 관리**를 누르면 기존 정렬·브랜드 필터·내 진열장·종류 등록이 열린다. 처음에는 접혀 사진이 먼저 보인다. 펼침 상태는 기존 RAM session에만 남으며 새 저장 키는 없다.
- 도구를 접어도 적용 중인 브랜드와 건수를 표시하고 **모든 브랜드 보기**로 바로 풀 수 있다. 필터를 숨긴 채 일부 옷을 전체처럼 보이게 하지 않는다.
- 결과 카드(React/바닐라)의 기존44px 버튼에 **걸어 보기 → 내리기**를 표시한다. aria-pressed·키보드·기존 걸기 명령·4벌 한도는 그대로다.
- 이전 디자인(v1)의 도구는 항상 직접 보이며 카드·상세와 저장/백업 계약은 유지한다.

## 운영·외부 조건 확인 메모

- 실제 기존 본인용 앱은 인증된 상태로 홈·빈 개인 자료 미리보기·초대 관리 화면을 읽어 확인했다. 초대 표는 '아직 만든 초대가 없어요'였다. 초대·가입·삭제를 실행하지 않았다.
- [Anthropic 공식 모델 문서](https://platform.claude.com/docs/en/models/overview)에서 현재 `claude-haiku-5-5` 모델 ID와 이미지 입력 지원을 확인했다. 설정/문서 확인을 실제 호출 성공으로 바꾸지 않는다.
- [Open-Meteo 약관](https://open-meteo.com/en/terms)은 무료 API를 비상업 용도로 제한한다. 현재 비공개 시험과 상업 출시는 구분하며, 상업 공개에 무료 경로 사용 권한이 확보됐다고 쓰지 않는다. 공급처 변경·유료 플랜은 별도 확인/승인 사항이다.
- [Google 로그인 지침](https://developers.google.com/identity/branding-guidelines?hl=en)과 [Kakao 공식 로그인 문서](https://developers.kakao.com/docs/ko/kakaologin/rest-api)의 디자인 가이드를 운영 마감에서 대조한다. 실제 OAuth 앱·키·메일 발신 도메인이 준비됐다는 뜻은 아니다.
