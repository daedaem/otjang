# 상담 화면 React 이전 (WO-06)

이 작업은 WO-05를 바탕으로 한다. 담당은 Claude 패션(Opus 5.5), 브랜치는 `claude/wo-06-consult-20261027`이다. 범위는 코디 상담 화면과 아래 입력 바를 React로 옮기는 것이다. 질문을 근거 상품으로 묶는 방법(`grounding`), 서버 요청, 주제 판단, 예산 대조 같은 상담 규칙은 바꾸지 않았다.

## 기준선 검사 (먼저 추가)

상담 화면에는 전용 브라우저 검사가 없었다. 그래서 바닐라의 현재 동작을 `e2e/consult.spec.ts` 4개로 먼저 고정했다(`11ebb23`, 바닐라에서 3번 반복 통과). AI 답은 모두 합성이다.

- 빈 상담은 예시 질문을 보여 준다. 기다리는 동안 "생각하는 중이에요"를 띄우고 입력을 막는다.
- 답은 문장, 가격 대조 줄, AI 응답 정보(모델·응답 ID)와 함께 보여 준다. 카드는 후보 안의 ID만 보여 주고, 각 카드는 걸 수 있다(상담 화면에는 아래 띠가 나오지 않는다).
- 주제를 벗어나면 정해 둔 거절 안내를, 오류면 오류 문구를 보여 준다. 300자를 넘으면 안내만 하고, 빈 질문은 입력으로 초점을 돌린다. 어느 경우든 추가 전송은 없다.
- 이어 묻기는 앞 대화를 `history`로 보낸다. 상담은 새로고침해도 남고, 목록·다시 열기·지우기가 된다.
- 앱 목록에 없는 브랜드는 국내 쇼핑몰 버튼을 보여 주고, 누를 때만 검색한다.

## 무엇을 바꿨나

- **같은 규칙:** `screen.html`의 `consultModel()`이 React 상담에 필요한 값을 만든다. 상담 정렬(최근순), "주고받은 말" 개수, AI 응답 정보, 후보 카드 규칙은 바닐라 `V.consult`·`chatTurnHtml`과 같다. AI 응답 정보는 `aiResponseInfo`로 검증된 값만 쓴다. 카드는 앱 목록에 있는 상품 ID만 쓴다.
- **React 화면:** `src/consult/`(`EOUL_CONSULT_LOAD` 섬).
  - 상담 목록: 예시, 이전 상담, 지우기, 모두 지우기
  - 상담 내용: 내 질문, 거절, 오류, 답(대조 줄, AI 정보, 카드)
  - 카드: 걸기, 4벌 한도 안내를 3.2초 표시
  - 입력 바: `#bar`로 포털한다.
- **공급처:** 앱에 없는 브랜드의 국내 쇼핑몰 검색은 `src/retail`의 `DomesticButtonPanel`(누를 때만 검색)로 옮겼다. 결과 표시는 WO-03a 패널과 같다.
- **기존 흐름 재사용:** 질문은 `askConsult`를 그대로 부른다. 상담 저장, 새 상담, 목록, 지우기 확인 시트도 기존 것을 쓴다. 바닐라처럼 갱신할 때마다 마지막 대화로 스크롤한다.
- **이중 처리 방지:** React 버튼은 `data-ask`, `data-thread`, `data-delthread`, `data-delall`, `data-newchat`, `data-chatlist`, `data-hang`, `data-pid`, `data-adpick-search`를 쓰지 않는다.
- **바닐라 경로 유지:** `?ui=vanilla`이거나 섬을 불러오지 못하면 바닐라 상담을 쓴다. 이때 "새 상담 화면을 열지 못해 기존 화면으로 열었어요."라고 알린다.
