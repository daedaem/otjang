# 옷 타일·날씨 상품 카드·체험용 옷 정보 시트 React 이전 (WO-08c)

이 작업은 WO-08b를 바탕으로 한다. 담당은 Claude 패션(Opus 5.5), 브랜치는 `claude/wo-08c-tiles-20261027`이다. 앞선 WO에서 React 섬은 screen.html이 만든 HTML 조각을 그대로 끼워 넣었다. 이번 범위는 그 조각들을 React로 그리는 것이다.

- 상품·내 옷·코디 조각 사진 칸(`productPic`, `garmentPic`, `piecePic`)과 사진이 없을 때의 색 카드(코어 `photoHtml`)
- 날씨 카드의 부족 아이템 상품 카드(`cardHtml`)
- 체험용 옷의 옷 정보 시트(바닐라 `garmentSheet`)와 그 안의 코디 카드(`lookHtml`), 등록 상태 줄(`crowdLine`)

이 단계로 React 섬이 screen.html의 HTML을 끼워 넣는 곳이 없어졌다. 다만 라쿠텐 출처 표시 문구는 원문 그대로 둔다(WO-03).

## 무엇을 바꿨나

- **계산은 한 곳:** 무엇을 보일지는 데이터 모델이 정하고, 바닐라 HTML과 React가 그 모델을 그린다.
  - 코어 `M.photoInfo()`: `photoHtml()`과 같은 결과를 데이터로 준다(사진 주소·대체 글·비슷한 사진 여부, 없으면 색·글자색·종류 이름).
  - screen.html의 칸 모델 `productTile`·`garmentTile`·`pieceTile`, 코디 카드 모델 `lookModel`, 등록 상태 모델 `crowdModel`이 있다. 바닐라 템플릿도 이 모델로 그린다.
- **React 조각:** `src/tiles/Tile.tsx`(`Tile`, `CorePhotoView`)가 칸을 그린다. 상세의 같은 옷·코디 칸, 결과·비교·기록의 색 카드, 날씨 카드의 옷 칸, 종류·색으로 넣기의 종류 그림, 홈·등록 화면의 사진 없는 상품 칸이 이것을 쓴다. 사진을 불러오지 못하면 바닐라 `onerror`처럼 색 카드로 바뀐다.
- **날씨 부족 아이템 카드:** 결과 화면의 React 카드(`results/Grid.tsx`의 `Card`)를 그대로 쓴다.
  - 걸기와 내리기, 상품 열기는 바닐라 `toggleHang`·`data-pid`와 같은 규칙이다.
  - 네 벌이 이미 걸려 있으면 바닐라 `showCardNote()`처럼 걸기 버튼 아래에 3.2초 동안 안내를 보인다.
- **체험용 옷 정보 시트:** WO-08a의 공통 시트 섬(`garment`)으로 연다. 사진 칸, 이름·설명, 출처 줄(Open Products Facts 또는 등록 상태와 판매처 링크), 색 묻기, 이 옷으로 입을 수 있는 코디 수와 카드 두 개, 색 바꾸기와 옷장에서 빼기가 있다. 체험용이 아닌 옷은 기존처럼 React 편집 화면(프로필 섬)으로 연다.
- **바닐라 경로 유지:** `?ui=vanilla`이거나 섬을 불러오지 못하면 바닐라 템플릿과 시트를 그대로 쓴다.
