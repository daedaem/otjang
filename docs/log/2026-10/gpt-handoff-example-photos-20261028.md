## 이번에 이어받아 마친 범위

대표가 이 Codex 대화에서 14종 상품 예시 이미지 생성을 요청했고, '나머지도 다 계속하고 ZIP으로' 요청해 전체 생성·압축 보존을 완료했다. 앞선 #103이 1~5번만 앱에 포함했고, 6~14번이 전달 대기로 남아 있어 같은 세트의 나머지 9개를 연결했다.

- 남성 체험용 8벌·여성 체험용 7벌에 14종을 대응한다. 흰 스니커즈는 남녀 공용 같은 예시 파일이다.
- 원본 PNG는 로컬에 보존하고 기존과 같은 720×900 WebP(품질78, 메타데이터 제외)만 포함한다. 추가 9개 166,842바이트, 전체 14개 232,148바이트.
- 출처·원본/결과 SHA256은 [예시 사진 안내](../../../app/lite/public/examples/README.md)·[명세](../../../app/lite/public/examples/manifest.json)에 남긴다.
- '예시 사진' 표시와 체험용 id·종류·색 대응을 유지한다. 직접 등록한 내 옷에 예시 사진을 붙이지 않으며, 색을 바꾼 체험용 옷에 이전 색 사진을 계속 붙이지 않는다.
- 기본 체험용 항목은 사진 표시 설정이 켜져도 외부 상품 사진을 요청하지 않는다. 실제 상품 전체의 표시/공개 권리가 확인됐다는 뜻은 아니다.
- 약관 초안의 `[운영자 이름](이하 …)`가 잘못된 Markdown 링크로 해석되는 표기만 인라인 코드로 감쌌다(법적 문장 변경 없음).
- docs 첫머리의 10-27 담당·WO-03 상태를 10-28 인계 기준으로 맞췄다. 과거 작업 기록·요구 결정은 보존했다.
