## 지금 앱과 맞지 않는 점

이 결정을 그대로 만들려면 지금 앱의 세 가지 전제가 바뀐다. 그래서 바로 코드를 쓰지 않고 이 문서부터 쓴다.

| 지금 | 커뮤니티에 필요한 것 |
|---|---|
| Worker는 **대표 한 사람 전용**이다(`PRIVATE_AUTH_MODE=session`, 앱 비밀번호 하나). [시스템 인수인계](../../system-handover.md) 4장 | 여러 사람의 계정, 가입·로그인·탈퇴 |
| 사진은 **기기 밖으로 보내지 않는다**(R22·10-25 결정). 서버는 사진을 받지 않는다 | 올린 코디 사진을 서버에 저장하고 다른 사람에게 보여 준다 |
| 무신사 사진·상품 자료는 **비공개에서만** 쓴다(10-19) | 다른 사람이 보는 화면에는 무신사 사진이 나오면 안 된다 |

옛 서버(`app/server`)에는 회원 코디가 구현돼 있었다([기록](community-20261015.md)). 지금 Worker 앱에는 없다. 그 기록의 규칙(공개 동의, 신고·차단, 저장 상한, EXIF 제거, 로그에 내용 안 남김)은 그대로 옮긴다.

## 만드는 순서 (Claude 추천)

공개는 마지막이고 스위치로 막아 둔다. 각 단계는 PR 하나씩이다.

1. **C1 화면과 자료 형식 (비용 없음).**
   - 코디 공유 화면을 만든다. 피드, 글 하나, 올리기(코디 고르기 → 사진 → 한마디 → 미리보기 → 동의).
   - 글 형식과 검증 함수를 코어에 둔다. 옷 ID·메모·구매 링크는 보내지 않는다.
   - 아직 서버에 올리지 않는다. 기기 안의 가짜 저장소로 동작하고, 화면에 '미리보기'라고 밝힌다.
2. **C2 서버 저장 (D1, 지금 쓰는 무료 범위).**
   - `community_posts`, `community_reports`, `community_blocks` 테이블을 만든다.
   - 스위치 `COMMUNITY_MODE`(기본 `off`)를 둔다.
   - 대표 한 사람 로그인으로만 써 본다.
3. **C3 사진 저장 (R2, 대표 승인 필요).**
   - R2를 켜려면 Cloudflare 계정에 결제 수단 등록이 필요하다는 안내가 있다(확인 필요). 무료 범위는 저장 10GB로 알려져 있다(확인 필요). 그래서 **계정 설정 변경·잠재 비용**이라 대표 승인 전에는 하지 않는다.
   - 앱이 올리기 전에 크기를 줄이고(긴 변 1080px 정도) EXIF를 지운다.
   - 서버 전체 상한(예: 8GB)과 회원별 상한을 둔다. 상한에 닿으면 사진 없는 글만 받는다. 무료 범위를 넘는 비용이 생기지 않게 한다.
4. **C4 계정 (대표 결정 필요).** 누구나 가입하려면 로그인 방식을 정해야 한다. 아래 표.
5. **C5 공개 전 준비.** 이용약관·개인정보처리방침·신고·게시중단 절차, 공개 화면의 무신사 사진 끄기, 신고 처리 화면을 만든다.
6. **공개.** 대표 승인으로 스위치를 켠다.

## 대표가 정할 것

### 1. 로그인 방식 (C4 전에)

| 순위 | 방식 | 좋은 점 | 나쁜 점 |
|---|---|---|---|
| 1 | **카카오 로그인** | 한국 사용자가 가장 익숙하다. 비밀번호를 우리가 보관하지 않는다 | 대표가 카카오 개발자 앱을 등록해야 한다(계정 추가). 비즈 앱 심사 조건은 확인 필요 |
| 2 | 구글 로그인 | 등록이 비교적 간단하다 | 한국 패션 사용자에게는 카카오보다 덜 익숙하다[추론] |
| 3 | 이메일 + 비밀번호 | 외부 앱 등록이 없다 | 비밀번호 재설정 메일 발송 서비스가 필요하고(새 서비스·비용 가능), 비밀번호 보관 책임이 생긴다 |

추천: 카카오 하나로 시작하고 구글을 나중에 더한다. 둘 다 대표가 앱을 등록하고 키를 Cloudflare Secret에 직접 넣는다. Claude는 키를 보지 않는다.

### 2. 운영자 정보 (C5 전에)

이용약관·개인정보처리방침에는 운영자 이름과 연락처, 신고 처리 기간이 들어간다. 대표가 정해 준다. 법적 요건(정보통신망법의 게시판·임시조치, 개인정보보호법의 처리방침 항목, 청소년 보호)은 Claude가 정리하되 확정은 전문가 확인이 필요하다.

### 3. R2 켜기 (C3 전에)

대표가 Cloudflare에서 R2를 켜고 버킷을 만든다. 결제 수단 등록이 필요하면 그 판단도 대표가 한다.

### 4. 서버 (10-28 09:03 대표 "필요하면 AWS 서버 구매")

Claude 추천 순위:

1. **Cloudflare 안에서 해결한다.** 사진은 R2, 글은 지금 쓰는 D1이다. 무료 범위를 넘으면 Workers 유료 플랜(월 5달러로 알려짐, 확인 필요)을 쓴다. 인증·배포·검사가 이미 여기 있어 옮길 것이 없다.
2. 사진만 AWS S3에 둔다. 다른 사람이 사진을 볼 때마다 전송 요금이 붙는다(R2는 전송 요금이 없는 것으로 알려짐, 확인 필요). 키 관리처도 둘로 는다.
3. **AWS로 서버를 옮기는 것은 추천하지 않는다.** Worker·D1·로그인·자동 배포를 다시 만들어야 하고, 서버 관리(보안 패치·백업)를 대표가 떠안는다. 초기 커뮤니티 규모에서 얻는 것이 없다[추론].

어느 쪽이든 결제는 그 단계에서 대표가 승인한다.

## 바로 할 수 있는 것

C1은 새 비용·계정·공개가 없다. 대표 승인 없이 시작할 수 있다. C2도 지금 쓰는 D1 무료 범위 안이고 스위치로 꺼 두므로 같다.
