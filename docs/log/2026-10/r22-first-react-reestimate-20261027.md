## 얻은 구현 근거

- 단순 JSX 이전으로 끝나지 않았다. 실제 저장 원문·등록 이력·사진 원본 보존, 출처가 없는 이미지의 대체 금지, 첫 방문 캐시, 자동 구형 화면 복귀, URL 정리, 실제 DOM 실측 비례, 포인터 가림을 함께 확인해야 했다.
- React에서 도메인을 직접 import하면 카탈로그가 다시 묶일 수 있었다. 기존 코어의 읽기 전용 통로를 공유해 데이터 중복을 피했다. 다음 속성·실측 화면도 같은 경계를 쓴다.
- 같은 합성 자료/viewport 캡처와 실제 클릭 검사는 다른 증거다. 두 가지를 모두 남기고, body 글자 확대만으로 고정 px 텍스트까지 두 배라고 주장하지 않는다.
- 저장 계약을 확장하는 부분과 화면을 실제로 연결하는 부분을 분리한다. 사진 포함 백업을 먼저 한 B2a→B2b 순서와 같이 B3도 초안/출처/오래된 화면의 덮어쓰기 보호부터 확인한다.
