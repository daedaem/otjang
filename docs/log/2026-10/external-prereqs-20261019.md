# 미연결 네 영역의 최소 실행 순서 (2026-10-19)

> 문서 시점: 2026-10-19. 당시의 검토·구현 기록을 보존한 자료입니다. 현재 결정·우선순위·운영 상태는 [최신 문서 목차](../../README.md)를 확인합니다. 아래의 “지금·완료·다음”은 별도 갱신 표시가 없으면 당시 기준입니다.

전체 목표를 실제로 닫으려면 외부 의존성이 있는 네 영역이 남는다. 각 영역에서 **무엇이 선행되어야 하는지**를 최소 순서로 적는다. 무료 또는 이미 있는 인프라로 되는 것을 앞에 둔다. 이용 가능 여부·권리는 추측하지 않고 "확인 필요"로 표시한다. 계정 생성·비용 지출·사진 외부 전송은 대표가 결정·실행하는 일이며, Claude·Codex가 대신하지 않는다. 대표가 아직 보유 API·서버 여부에 답하지 않았으므로, 답에 따라 갈리는 곳은 분기로 적는다.

## 0. 공통 전제 (대표 답이 필요한 것 3개)
| 질문 | 답에 따라 달라지는 것 |
|---|---|
| A. 이미 갖고 있는 API 키·제휴 계정이 있는가(쿠팡 파트너스, 무신사 큐레이터, 기타) | 있으면 1영역의 1단계를 건너뛴다 |
| B. 24시간 켜 둘 수 있는 PC 또는 이미 쓰는 클라우드(VM·NAS)가 있는가 | 있으면 4영역을 0원으로 시작한다 |
| C. 사업자 등록 여부와 시점 | 제휴 정산·플랫폼 제휴 제안의 전제 |

답이 없어도 아래 "지금 할 수 있는 것"은 진행한다. 문장 30개와 마찬가지로, 대표 답이 없다고 개발이 멈추지는 않는다.

## 1. 상품·옵션·현재 가격 공급 (계약: 정확한 상품·옵션·가격 비교)

**지금 상태:** 수집 카탈로그 891개(권리 미확인), 판매처 1곳 수집일 가격, 사용자가 직접 적는 판매처 가격 기록. 네이버 쇼핑 검색 API는 2026-07-31 종료(공식 공지 32564, 약관 부칙 2조 3항)라 차단.

**최소 순서**
1. **지금(0원, 코드):** 공급원 추상화(`server/src/supply.js`)에 "권리 상태" 필드를 둔다. `collected`(수집, 비공개 시험 전용) / `affiliate`(제휴 승인 자료) / `manual`(사용자 기록). 화면은 이미 "수집일 가격"을 밝히고 있으니, 공개 빌드에서는 `collected`를 숨길 수 있는 스위치만 추가한다. 상품을 지우거나 바꾸지 않는다.
2. **지금(0원, 코드):** 사용자가 붙여 넣은 링크의 **공개 메타(제목·가격·대표 이미지 주소)**를 서버가 그 요청 한 건만 읽어 글자로 돌려주는 경로를 설계한다. 저장은 글자만, 사진은 사용자 기기에서 표시. **구현 전에 약관 검토가 필요하다(확인 필요).** 설계·검사만 먼저 하고, 켜는 것은 대표 결정.
3. **대표(0원, 신청):** 쿠팡 파트너스 가입(채널 필요, 판매 이력 불필요 — 블로그 출처, 공식 확인 필요), 무신사 큐레이터·에이블리 크리에이터 신청, 링크프라이스 어필리에이트 가입 후 패션 머천트·상품 DB 제공 여부 문의. 모두 신청 자체는 무료로 알려져 있다(확인 필요).
4. **대표(유료, 결정):** 지식재산권 변호사 1회 상담. 질문 3개는 `product-data-plan-20261019.md` 4장.
5. **승인 뒤(코드):** 승인된 공급원 어댑터 1개를 `supply.js`에 붙인다(쿠팡은 최종 승인 뒤 API, 링크프라이스는 상품 DB 형식 확인 뒤). 확인 시각을 붙여 "확인한 판매처 n곳 중 총액이 가장 낮은 곳"으로만 쓴다. "현재 최저가"라고 쓰지 않는다.
6. **공개 전:** `collected` 자료는 공개 빌드에서 숨기거나 제휴 자료로 교체. `no-referrer`를 뺀다.

**완료 기준:** 권리 상태가 `affiliate`인 공급원 1개 이상이 연결되고, 그 자료로 검색→비교→판매처 이동이 동작하며, 가격마다 확인 시각이 붙는다.

## 2. 확인된 주문 이벤트 (계약: 구매와 구매 후 관리)

**지금 상태:** 사용자 직접 기록(사기로 함 → 주문 → 받음 → 보유/반품). 구매내역 가져오기는 PC 확장프로그램 시험 기능(실주문·Windows 미검증).

**최소 순서**
1. **지금(0원, 코드):** 시험 기능의 Windows 실행 경로를 대표 PC에서 1회 확인(설치·복사·붙여넣기). 실패하면 어디서 막히는지만 기록.
2. **지금(0원, 코드):** 가져온 주문에 `provenance: 'imported'`가 이미 붙는다. 여기에 "확인된 거래"와 "사용자 기록"을 화면에서 구분하는 표시를 유지한다(이미 있음). 추가 구현 없음.
3. **대표(확인 필요):** 구매자용 주문 조회 API를 제공하는 플랫폼이 있는지 확인. 2026-10 조사에서는 확보된 것이 없다. 쿠팡 파트너스 API는 **판매 보고용**이지 구매자 주문 조회가 아니다(확인 필요).
4. **대안(0원, 코드, 약관 검토 뒤):** 주문 확인 **메일**을 사용자가 앱에 붙여 넣으면 글자에서 주문번호 해시·상품명·금액·날짜만 읽는 경로. 메일 계정 연동은 하지 않는다(외부 전송·권한 문제). 이것도 "사용자가 가져온 기록"이지 확인된 거래가 아니다.

**완료 기준:** 플랫폼이 발급한 주문 이벤트(API 또는 서명된 알림)를 받아 `confirmed`로 저장할 때. 그 전까지는 모든 주문이 "사용자 기록"이며 화면도 그렇게 말한다. **외부 제휴 없이는 닫히지 않는다.**

## 3. 사진 상품 식별·가상 착용 (계약: 조합·가상 착용, 등록 편의)

**지금 상태:** 기기 안 CLIP 후보 제시(약 154MB, "고급" 경로), 기기 안 배경 지우기(U-2-Netp), 무료 CPU 가상 착용 시험(`experiments/vton-fashn-1.5`, 채택 전). 사진 외부 전송 금지.

**최소 순서**
1. **지금(0원, 코드·측정):** 사진 상품 식별은 **대표 본인 옷 사진 20장**으로 기기 안 CLIP 후보의 정확도(상위 3개 안에 맞는 종류가 있는 비율)를 잰다. 사진은 대표 PC에만 둔다. 결과 수치가 나오기 전에는 화면에 "추정"으로만 둔다.
2. **지금(0원, 코드):** 가상 착용은 같은 사진·상품 5쌍으로 CPU 시험 도구의 결과·시간을 기록한다. 채택 기준(한 장당 시간, 눈으로 본 품질, 실패율)을 먼저 적는다.
3. **대표(결정):** 가상 착용을 제공하려면 (a) 기기 안/대표 서버에서만 돌릴지, (b) 비용, (c) 사진 전송 동의와 삭제 정책을 정해야 한다. 외부 유료 API(FASHN 등)는 "사진이 외부로 나간다"는 제약과 충돌하므로 대표 승인 없이는 검토하지 않는다.
4. **채택 뒤(코드):** 결과 화면에 "합성 이미지이며 핏·사이즈 보장이 아니다"를 고정 표시.

**완료 기준:** 사진 식별은 측정 수치 공개 + "추정" 표시 유지. 가상 착용은 채택 기준 통과 + 동의·삭제 정책 + 한계 고지. **비용·동의 결정은 대표 몫.**

## 4. 상시 운영 (지인 파일럿부터 필요)

**지금 상태:** Docker 운영 묶음(서버 + 이름 있는 Cloudflare 터널 + Litestream 백업 + 복구 훈련) 완성, 실제 터널·Windows Docker Desktop·S3 복제 미검증. 개인 테스트는 임시 터널.

**최소 순서**
1. **B=있음(0원):** 그 PC/클라우드에 `deploy/README.md` 1~2단계대로 Docker 묶음을 올린다. 필요한 것은 Cloudflare 계정(무료 등급으로 알려짐, 확인 필요)과 도메인(연 1~2만원 추정, 확인 필요). 백업은 로컬 폴더로 시작.
2. **B=없음:** 임시 터널(개인 테스트)로 계속 가고, 지인 파일럿 전에 저가 VM 또는 가정용 PC 상시 운영을 대표가 결정. 비용 추정은 `business-roadmap-20261015.md` 참고(확인 필요).
3. **공통(0원, 코드):** 초대 코드 가입, 운영자 정보(정책 화면), 커뮤니티·서버 사진 분석 기본 꺼짐은 이미 있다. 파일럿 전 점검 목록: 복구 훈련 1회, 재부팅 뒤 자동 시작, 백업 폴더 권한.

**완료 기준:** 고정 https 주소에서 24시간 응답, 복구 훈련 통과, 백업 자동. **계정·도메인은 대표가 만든다.**

## 5. 한 줄 순서 (전체)
1. 코드(지금): 공급원 권리 상태 + 공개 빌드 스위치, 링크 메타 읽기 설계, 사진 식별 정확도 측정, VTON 채택 기준 기록, 구매내역 Windows 1회 확인.
2. 대표(무료 신청): 쿠팡 파트너스·무신사 큐레이터·에이블리·링크프라이스. Cloudflare 계정·도메인(B에 따라).
3. 대표(유료·결정): 변호사 상담, 가상 착용 제공 여부·동의 정책, 사업자 등록 시점.
4. 코드(승인 뒤): 제휴 공급원 어댑터, 공개 빌드 자료 교체, 상시 운영 배포.
5. 끝까지 외부 의존으로 남는 것: 확인된 주문 이벤트. 플랫폼 발급 없이는 "사용자 기록"으로 남긴다.

## 6. 하지 않는 것
Claude·Codex가 계정을 만들거나, 비용을 쓰거나, 사진을 외부로 보내지 않는다. 이용 가능 여부와 권리는 공식 자료로 대표가 확인한다. 외부 의존성 때문에 닫히지 않는 항목은 "완료"로 바꾸지 않는다.
