# 비교 우선 동선·가벼운 첫 화면 — 2026-10-15

> 문서 시점: 2026-10-15. 당시의 검토·구현 기록을 보존한 자료입니다. 현재 결정·우선순위·운영 상태는 [최신 문서 목차](../../README.md)를 확인합니다. 아래의 “지금·완료·다음”은 별도 갱신 표시가 없으면 당시 기준입니다.

서비스 UX 재설계(PR #26, `37caa78`) 위에서 전체 점검을 했고, 그중 작업량이 작고 효과가 큰 묶음을 이 문서에 정리한다. 디자인 토큰 정리, 설치형 앱(PWA), 옷장 분석 화면 줄이기는 별도 작업으로 남긴다.

## 바꾼 것

| 영역 | 이전 | 이후 |
|---|---|---|

### 원탭 비교 기록의 규칙

- 비교를 누르면 기록을 바로 저장한다. 판매처에 다녀오는 사이 탭이 새로 열려도 비교와 답이 남게 하려는 것이다.
- 사용자가 직접 닫을 때(닫기 버튼, 바깥 누르기, Esc) 저장 당시와 내용이 똑같으면 그 기록을 지운다.
- 질문에 답하거나 판단을 고르면 기록이 달라졌으므로 남긴다.
- 페이지가 새로 열렸거나 다른 계정·다른 기록으로 바뀌었으면 지우지 않는다.
- 결정 줄에 "고르면 구매 여정에 남아요. 그냥 닫으면 기록하지 않아요."라고 미리 알린다.
- 링크로 가져온 상품(직접 입력)은 지금처럼 바로 구매 여정에 남는다.

## 검증

- 앱 테스트 525개 통과(아래 6개를 빼고 새 테스트 6개를 넣어 총수는 같음). Codex의 "탭 전환 대기 중 끼어들기" 테스트 6개는 탭 전환이 없어졌으므로 아래 테스트로 바꿨다.
  - 저장 대기 중 끼어들기 3개
  - 다시 열기는 읽기 전용 1개
  - 그냥 닫으면 기록 없음, 답하거나 판단하면 남음 1개
  - 상품 상세에서 비교가 주 버튼 1개
  - 색 미리 선택 없음과 이름 표시(기존 등록 테스트에 추가)
- 서버 테스트 35개 통과, 1개 생략(모델 런타임 없음). 새 테스트는 다음을 확인한다.
  - 압축 없음·gzip·brotli·`br;q=0` 각각의 응답
  - 같은 ETag는 304
  - 빌드를 바꾸면 ETag도 바뀜
- Chromium 390×844 밝은·어두운 모드에서 17개 화면을 확인했다.
  - axe 위반은 색 고르기 마지막 줄 하나뿐이다. 고정된 저장 버튼에 처음 위치에서 가려지기 때문이고, 끝까지 내리면 저장 버튼 위로 올라온다(마지막 줄 아래끝 561px, 저장 버튼 위끝 747px).
  - 12px 미만 글자는 의도한 캡션 1종뿐이다.
  - 44px 미만 누르는 영역은 옷장 분석의 상품명 글자 링크뿐이다. 같은 동작을 하는 사진 버튼이 바로 옆에 있다.
- Lighthouse 모바일(모의 느린 네트워크)을 실제 서버 코드(`createApp`)로 쟀다. 압축 전 수치는 같은 빌드를 압축 없이 보낸 측정이다.

## 남은 일

- 실제 휴대폰과 실제 배포 서버에서는 측정하지 않았다. 리버스 프록시가 따로 압축하는 환경이면 이 서버 압축은 중복이지만 해가 없다(`Vary: Accept-Encoding`).
- favicon이 없어 `/favicon.ico`가 404를 낸다. 설치형 앱 작업에서 아이콘과 함께 넣는다.
- 상품 목록 데이터(391KB)를 별도 파일로 나누면 멈춤 시간을 더 줄일 수 있다(다음 성능 작업).
- 디자인 토큰 정리, 설치형 앱, 옷장 분석 화면 줄이기, 찜과 구매 여정 합치기는 별도 PR로 한다.
