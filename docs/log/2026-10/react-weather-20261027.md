# 날씨·지역 공유 React 이전 (WO-02)

기준 master는 WO-01 홈을 병합한 `bb3f5dd`(#89)다. 담당은 Claude 패션(Opus 5.5)이며 브랜치는 `claude/wo-02-weather-20261027`이다. 이 단계는 홈과 코디의 날씨 카드, 날씨 지역 선택을 React로 옮기는 일이다. 상품 카드·결과 화면·공통 UI 전체 이전이나 실기기 확인은 아니다.

## 무엇을 바꿨나

- **계산은 한 곳:** `screen.html`의 `weatherModel()`이 날씨 카드 내용을 데이터로 만든다. 바닐라 카드(`weatherHtml`)와 React 카드가 같은 모델을 그린다. 바닐라 HTML 출력은 그대로 유지했다.
- **상태 변경도 한 곳:** `weatherCtl`이 날짜, 다른 조합, 예시 날씨, 지역 적용, 불러오기를 맡는다. React 카드는 구독해서 다시 그린다. React 카드가 없는 바닐라 화면만 예전처럼 화면 전체를 다시 그린다. 날씨를 받은 뒤 홈·코디 전체를 다시 그리던 경로는 React 화면에서 더 이상 쓰지 않는다.
- **React 카드:** `src/weather/WeatherCard.tsx`. 홈(`where="home"`)과 코디의 접힌 날씨 칸(`where="looks"`)이 같은 부품을 쓴다. 바닐라와 같은 클래스·문구·접근성 이름("오늘 날씨 코디", "날짜", "예시 날씨 고르기")을 쓴다. 예시 날씨 칩 묶음에는 `role="group"`을 더했다.
- **지역 선택:** `src/weather/PlaceSheet.tsx`. 바닐라 시트와 같은 문구·클래스의 React 대화상자(`role="dialog"`, 제목 "날씨 지역")다. 열 때 첫 버튼에 초점을 두고, Esc·배경 누름으로 닫고, 닫힌 뒤 지역 버튼으로 초점을 돌려준다. 위치는 "지금 있는 곳을 내 지역으로"를 누를 때만 묻는다(기존과 같음). 지역 저장은 기존 `EOUL_WEATHER_PLACE.set`을 그대로 쓴다.
- **바닐라 경로 유지:** `?ui=vanilla`와 React 홈 로딩 실패 시의 바닐라 홈은 예전 날씨 카드와 지역 시트를 그대로 쓴다.

## 일부러 남긴 경계

옷 조각 타일(`piecePic`)과 "부족 아이템" 상품 카드(`cardHtml`)는 결과 화면 격자와 같은 공용 템플릿이라 모델에 HTML로 담아 React 카드 안에 넣는다. 걸기 버튼과 상품 열기는 기존 전역 클릭 처리를 그대로 탄다. 이 두 부품은 WO-03(검색 결과·공급처)과 WO-08(공통 UI)에서 React 상품 카드·옷 타일로 바꾼다. 이 경계 때문에 날씨 카드를 "모든 하위 부품까지 React"라고 쓰지 않는다.

저장 키와 형식은 바꾸지 않았다. 예시 날씨 선택은 기존 `eoul-d12-hang:ui`의 `wxEx`, 지역은 `eoul-weather:place`, 날씨 캐시는 `eoul-weather:last`를 그대로 쓴다.

**전후 캡처.** 같은 빌드에서 `?ui=vanilla`(바닐라 카드·시트)와 기본(React 카드·시트)을 네 상태로 캡처했다. 상태는 실제 날씨, 날씨 실패 후 예시, 빈 옷장 초대, 지역 창 열림이다. 처음 비교에서는 온도 줄과 기온 안내 줄 가장자리에서만 차이가 났다. 최대 차이는 58/255였고, 64를 넘는 픽셀은 없었다. 글자 위치는 같았다. React가 그 줄을 여러 text node로 나눠 그려 생긴 하위 픽셀 안티앨리어싱 차이였다. 두 줄을 바닐라 템플릿처럼 한 문자열로 합친 뒤에는 네 쌍 모두 파일이 바이트 단위로 같다. 그래서 React 캡처만 [`evidence/weather/`](evidence/weather/manifest.json)에 남겼다. 합성 옷장과 주입한 날씨를 썼고 개인 자료나 실제 위치·날씨 API는 쓰지 않았다.

**확인하지 않은 것.** 실기기, 설치 PWA, 실제 위치 권한 창, 실제 날씨 제공자 응답, 오프라인 재실행은 이 단계에서 확인하지 않았다(WO-09). 바닐라 날씨 카드와 지역 시트는 fallback으로 남아 있다. 실기기와 기존 자료 복원을 확인하기 전에는 지우지 않는다.
