# 상품 상세·구매 판단·비교 React 이전 (WO-04)

이 작업은 WO-03b를 바탕으로 한다. 담당은 Claude 패션(Opus 5.5), 브랜치는 `claude/wo-04-detail-20261027`이다. 범위는 상품 상세 화면, 그 아래의 구매 판단 바, 나란히 비교 화면을 React로 옮기는 것이다. 구매 기록 목록(WO-05), 공통 시트(WO-08), 실기기 확인(WO-09)은 이 범위에 들어가지 않는다.

## 기준선 검사 (먼저 추가)

상세·판단·비교에는 전용 브라우저 검사가 없었다. 그래서 바닐라의 현재 동작을 `e2e/detail.spec.ts` 6개로 먼저 고정했다(`d22cc4d`, 바닐라에서 3번 반복 통과).

- 상품 사실과 판단 기준을 보여 준다. 옷장이 비어 있으면 바로 "화이트 셔츠 있어요?"라고 묻는다. 중고 링크는 9곳이다. 실측·활용·거울로 들어가는 버튼이 있다.
- 결과에서 AI 순위를 받은 상품은 상세에서 "AI 순위 1위 · 추천"과 이유를 보여 준다.
- 상세에서 걸면 한 번 묻는다.
  - "없어요"를 누르면 "겹치는 셔츠가 없어요"로 바뀐다.
  - "있어요"를 누르면 색 시트에서 같은 색을 골라 옷장에 넣고, "비슷한 옷이 1벌 걸려 있어요"로 바뀐다.
- 구매 판단 바: 보류·안 살래요를 남기고 "바꾸기" 시트로 고칠 수 있다. 판매처 링크로 나갔다 돌아오면 한 번 묻는다("샀어요"를 고르면 "살게요로 남겼어요 · 주문·도착은 기록에서"). 다시 돌아와도 또 묻지 않는다.
- 계속 입는 옷은 바에서 "반품했어요"를 누르고 사유를 고르면 반품으로 기록되고 옷장에서 내려간다.
- 비교: 두 벌 미만이면 안내만 한다. 세 벌이면 표를 보여 주고, 같은 항목은 접어 두었다가 펼칠 수 있다. 내리기, 상품 열기도 된다.

## 무엇을 바꿨나

- **계산은 한 곳:** `screen.html`에 `detailModel()`, `decisionModel()`, `compareModel()`을 두었다. 바닐라 `V.detail`, `drawDecision`, `V.compare`는 이 모델로 예전과 같은 HTML을 만든다. 상세·바·비교의 13개 상태에서 리팩터링 전후 `#app`과 `#bar` HTML을 비교했고 모두 같았다.
- **React 화면:** `src/detail/`(`EOUL_DETAIL_LOAD` 섬). 상세와 비교를 담는다.
  - 상세: 사진(크게 보기), 큰 걸기 버튼(처음 걸면 튐, 4벌 한도 안내를 3.2초 표시, 묻기가 생기면 판단 상자로 스크롤), 상품 사실, 실측·활용·거울 진입, AI 이유, 판단 상자(묻기 버튼, 가진 옷 타일, 코디 2개, 가진 옷 걸기), 중고 링크를 그린다.
  - 구매 판단 바: `#bar`로 포털해서 그린다(보류·안 살래요, 바꾸기·반품·기록, 판매처 링크).
  - 비교: 같은 표를 그리고, 같은 항목은 아래로 모아 접어 둔다.
- **기존 명령 재사용:** 바꾸기·판매처에서 돌아옴 시트(`decisionSheet`), 반품 사유 시트(`returnSheet`), 색 시트(`answerOwn`, `addLike`), 크게 보기(`zoom`)는 바닐라 함수를 그대로 부른다. `drawDecision`은 React 상세가 열려 있으면 `#bar`를 덮어쓰지 않고 React에 갱신만 알린다. 그래서 시트에서 고른 결과가 React 바에 그대로 반영된다.
- **이중 처리 방지:** React 버튼은 `data-zoom`, `data-hang`, `data-own`, `data-addlike`, `data-measure`, `data-collection`, `data-mirror`, `data-dec`, `data-redecide`, `data-ret`, `data-tabgo`, `data-pid`, `data-unhang`, `data-back`, `data-disclose`를 쓰지 않는다.
- **스크롤·새로고침:** 실측·활용·거울에서 돌아오면 스크롤을 복원한다. `K.refresh()`가 오면 같은 상품 화면을 그 자리에서 갱신한다.
- **바닐라 경로 유지:** `?ui=vanilla`이거나 섬을 불러오지 못하면 바닐라 상세·비교를 쓴다. 이때 "새 상품 화면을 열지 못해 기존 화면으로 열었어요." 또는 "새 비교 화면을 열지 못해 기존 화면으로 열었어요."라고 알린다.

## 남긴 경계

- 가진 옷 타일(`garmentPic`)과 코디 조각 타일(`piecePic`)은 공용 템플릿 HTML로 넣는다. 사진이 없을 때의 색 타일도 코어 템플릿 HTML이다. 이 타일들은 WO-08에서 다룬다.
- 바꾸기·판매처에서 돌아옴·반품·색 시트는 바닐라 시트다. 공통 시트는 WO-08에서 다룬다.
- 판매처 링크를 누른 뒤 돌아왔을 때 묻는 조건(0.7초~30분, 같은 상품 화면)은 바닐라 `onReturn` 그대로다.

## 확인하지 않은 것

실제 판매처 페이지, 실기기 앱 전환(앱에서 판매처로 나갔다 돌아오기), 실제 사진의 크게 보기, 설치 PWA(WO-09)는 확인하지 않았다. 판매처 이동은 실제 주문 확인이 아니며, 기록은 사용자가 직접 남기는 것이다.
