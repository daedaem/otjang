# 행잇 (Hangit) — 이름과 마크

2026-10-27에 대표가 이름과 마크 결정을 Claude에게 맡겼다("브랜드 마크와 네이밍도 알아서 해주세요… 실제로 출시할 수 있는지까지 고려해서요"). 이 문서는 그 결정과 근거, 출시 전에 남은 확인을 적는다. 상표 출원과 도메인 구매는 하지 않았다. 둘 다 새 비용이라 대표 승인이 필요하다.

## 결정

- **이름:** 행잇. 영문 표기는 hangit(워드마크는 소문자), 문장 안에서는 Hangit으로 쓴다.
- **뜻:** hang it, "걸어 봐". 살까 말까 하는 옷을 내 옷장에 걸어 보고 정하는 이 앱의 핵심 동작이다. 앱의 '걸어 보기', 옷걸이 띠, '걸어 보고 사기'와 같은 말이다. 한국어로는 '행거'와 소리가 이어진다.
- **대표 기준과 대조**(10-22: 영어, 두세 글자, 토스 같은 가벼운 동작): 영어이고, 두 음절이며, 동작이다. 10-22부터 README 가명으로 써 온 이름이라 저장소·문서와도 이어진다.

## 마크

파일은 이 폴더에 있다. 앱 아이콘 PNG는 `app/lite/public/icons/`에 있다.

- **워드마크 `wordmark.svg`:** 소문자 hangit. 글꼴 없이 같은 굵기의 둥근 획으로 직접 그렸다(글꼴 사용권 문제 없음). i의 점 자리에 옷걸이 고리를 둬서 'hang it'의 it이 걸리는 자리를 표시한다. hang는 잉크색, it은 네이비다.
- **심볼 `mark.svg`, 아이콘 `icon.svg`:** 옷걸이. 고리는 워드마크의 i와 같은 한 획이다. 앱 아이콘은 네이비 바탕(#1f3f80)에 흰 옷걸이다. `icon-maskable.svg`는 안드로이드 둥근 자르기를 위해 78%로 줄였다.
- **색:** Daedaem 1.1.1의 딥 네이비 #1f3f80(어두운 화면은 #86a3d6), 잉크 #202025, 흰색. 옷 사진 주변은 무채색으로 둔다는 Daedaem 원칙을 따른다.
- **쓰는 곳:** 각 화면 위 막대의 이름 자리(바닐라·React 공통, `src/brand/Wordmark.tsx`와 screen.html `BRAND_WORDMARK`), 페이지 제목, 설치 이름(manifest·apple title), 아이콘.
- **아직 바꾸지 않은 것:** 앱 전체의 강조색은 아직 주황이다. 화면 색과 레이아웃은 WO-11 디자인 단계에서 바꾸고, 바꾸기 전에 대표에게 보여 드린다.
