# 지인 비공개 베타 계획 · 2026-10-12

**[사용자 결정, 10-12 23:10]** 첫 배포는 서버 없는 웹앱(서버형은 다음 단계), 첫 고객은 지인 5~20명 비공개 베타, 화면 이름은 "어울(EOUL)" 임시 사용.

## 무엇을 배포하나

- `app/` 의 웹 배포판: `npm run assets && npm run build:web` → `app/dist/web/` (index.html 약 0.2MB, 3D는 `closet.js` 약 11.7MB를 3D 탭을 처음 열 때만 받음, `manifest.webmanifest`, 아이콘 2장).
- 처음 열면 빈 옷장 + 환영 안내. "예시 옷장으로 둘러보기"로 합성 예시 13벌을 볼 수 있고, "내 옷장으로 시작"하면 예시는 지워진다.
- 옷장·사진·기록은 각자 브라우저(IndexedDB)에만 저장된다. 운영자 서버가 없어 운영자는 아무것도 보지 못한다. 분석 도구·추적 코드 없음.
- 이름은 `app/brand.json` 한 곳에서 바꾼다(지금 "어울 (가칭)", 0.5.0-beta).
- 서버와 맞추기는 "고급(개발용)" 안으로 접었다. 베타 사용자는 쓰지 않는다.

## 어디에 올리나 [제안, 사용자 확인 필요]

1순위: 기존 GitHub Pages(`gh-pages` 브랜치)의 하위 폴더 `beta/` → https://daedaem.github.io/otjang/beta/
- 0원. 앱 자체에는 개인 자료가 없고 소스도 이미 공개 저장소라, 링크가 알려져도 새로 드러나는 것은 없다.
- 단점: "비공개"는 링크를 아는 사람만 들어온다는 뜻일 뿐 잠금이 아니다. 검색 노출을 줄이려고 `noindex`를 넣는 것을 제안한다.
