## 무엇을 배포하나

- `app/` 의 웹 배포판: `npm run assets && npm run build:web` → `app/dist/web/`
  - `index.html` 389KB(gzip 약 103KB, 검증 카탈로그 포함). 3D 는 `closet.js` 11.7MB(gzip 약 6.3MB)를 3D 탭을 처음 열 때만 받는다. `manifest.webmanifest`, 아이콘 2장.
- **기준으로 딱 하나 추천(0.6.0)**: "사고 싶은 옷 골라 받기" → 용도(상관없음·카디건·셔츠 안에·한 장으로)와 꼭 지킬 조건, 중요한 기준(가성비·품질·브랜드·내 핏·스타일)을 누른 순서대로 고르면 상품 하나와 대안 둘, 이유·확인한 것/모르는 것·사이즈·확인일을 보여 준다. 판매처 링크로 나가고, "이걸로 할래요·다른 걸로·안 살래요", 산 뒤 2주 사이즈·만족을 묻는다. 지금은 흰 크루넥 티 한 품목, 공식 판매처 15개(폴로 2·퍼플 라벨 1·브룩스 브라더스 1·포터리 3·브론슨 1·유니클로 3·리바이스 2·헤인즈 2, 2026-10-13 확인. 포터리 1개는 긴팔). 상품 사진은 가져오지 않는다. 규칙은 `docs/rules-explained.md` 10절.
- 처음 열면 빈 옷장 + 환영 안내. **"자주 입는 옷 골라 넣기"**로 기본 옷 31종(셔츠·블라우스·스커트·원피스·힐 등) 가운데 가진 것과 비슷한 것을 눌러 한 번에 넣는다. 예시 옷장 A(셔츠·재킷)·B(원피스·스커트)로 먼저 둘러볼 수 있다.
- **옷 사진 여러 장으로 넣기**: 사진(한 번에 20장까지)마다 분류·종류만 고르면 색은 사진 가운데에서 뽑은 초안으로 들어가고, 사진이 옷장 카드에 보인다. 사진은 그 브라우저 안에만 남는다.
- **고민 중인 옷 바로 판정**: 종류·색·지금 마음만 고르면 판정이 나온다. 쇼핑 앱에서 복사한 링크·글을 붙여 넣으면 판매처(무신사·29CM 등, 도메인으로만)와 이름을 채운다. 링크는 열거나 읽지 않는다.
- **빈 옷장에서 첫 판정까지 13번** 누르거나 고른다(자동 측정. 예전 흐름은 옷 5벌+후보 1벌에 약 51번).
- **친구에게 물어보기**: 판정 요약을 그림(1080×1350)과 글로 만든다. 내 옷장의 옷 이름·사진은 넣지 않고, 후보 사진은 고를 때만 넣는다. 공유 기능이 있는 휴대폰은 공유 창, 아니면 그림 저장·글 복사.
- **결정 2주 뒤 한 번 묻기**: 산 옷은 몇 번 입었나·잘 샀나, 안 산 옷은 아쉬운가. 판정이 후회 구매를 줄였는지 보는 자료다.
- 설치(홈 화면에 추가)한 안드로이드 크롬에서는 쇼핑 앱의 "공유" 목록에 나타나 바로 후보로 넣을 수 있다(share_target, 아이폰 미지원).
- 한 번 연 뒤에는 **인터넷이 끊겨도 열린다**(서비스 워커. `beta/` 폴더만 맡고 옷장 자료는 다루지 않는다. 3D 도 한 번 받은 뒤에는 그대로 열린다).
- 옷장·사진·기록은 각자 브라우저(IndexedDB)에만 저장된다. 운영자 서버가 없어 운영자는 아무것도 보지 못한다. 분석 도구·추적 코드 없음.
- **보안 정책(CSP)**: 이 페이지 안의 스크립트(해시 지정)와 같은 주소의 closet.js 만 실행하고, 외부로 보내는 요청과 외부 스크립트는 막는다(자동 시험으로 확인). 링크를 눌러도 앱 주소를 넘기지 않고(no-referrer), 검색 제외 표시(noindex)를 단다.
- 이름은 `app/brand.json` 한 곳에서 바꾼다(지금 "어울 (가칭)", 0.6.0-beta). 서버와 맞추기는 "고급(개발용)" 안으로 접었다.

## 알려진 한계 (참여자에게도 안내)

- 아이폰 Safari 는 오래 열지 않으면 저장 자료가 지워질 수 있다고 알려져 있다 [확인 필요]. 앱이 백업 알림(3벌 이상, 14일마다)과 "홈 화면에 추가" 안내를 한다.
- 판정은 규칙(색·밝기·격식·무늬)이며 핏·소재·얼굴 분위기는 보지 않는다. 실사 착장은 없다. 규칙은 `docs/rules-explained.md`.
- 추천은 사람이 확인해 넣은 상품 안에서만 한다(지금 흰 크루넥 티 15개). 가격·재고는 확인한 날의 값이라 판매처에서 다시 확인해야 한다. 확인한 지 14일이 지나면 가성비를 낮추고 30일이 지나면 1등에서 뺀다. 판매처에서 수수료를 받지 않고, 순서를 돈으로 바꾸지 않는다.
- 3D 탭은 느린 4G(가정 1.6Mbps·150ms)에서 약 36초, 보통 LTE(가정 12Mbps·40ms)에서 약 8초 걸렸다(흉내 회선, GPU 없는 환경. `npm run check:perf`). 첫 화면은 두 회선 모두 1초 안.
- 실제 아이폰·Safari·안드로이드 기기에서는 아직 확인하지 않았다(헤드리스 Chromium 1280px·390px). Safari 엔진 시험은 Playwright WebKit 이 설치된 PC 에서 `BROWSER=webkit npm run check:web` 으로 돌릴 수 있게 해 두었다.
