# Claude 디자인팀 5안 (2026-10-20)

Codex가 정리한 수상작 분석(공식 기록 241건 중 대표 이미지 238건 시각 검토, 앱 실사용 시험 아님)의 6가지 기준을 AI 디자인팀 5개가 각자 다르게 해석해 만든, 실제로 클릭되는 PC·모바일 웹앱 시안이다.
**AI가 디자이너·프론트엔드 개발자 역할로 만든 시안이고, 사람 수상 디자이너는 참여하지 않았다.** 세계 최고 수준은 목표일 뿐 검증된 결과가 아니다.

## 실행
- 파일로 바로 열기: 저장소를 받은 뒤 `app/mockups/claude-five-20261020/<안>/index.html`을 브라우저로 연다(주소는 `#/…` 해시라 file://에서도 동작).
- 서버로 열기: `cd app/mockups && python3 -m http.server 8799` → `http://localhost:8799/claude-five-20261020/01-anatomy/index.html` 등. **`app/mockups`(또는 그 위)를 서버 루트로 둬야** `../../ux10v2/…` 경로가 열린다. 링크로 올릴 때도 `claude-five-20261020/`와 `ux10v2/shared`, `ux10v2/design/cutouts.js`, `ux10v2/links/shared/photo-kinds.js`를 같은 상대 위치로 함께 올린다.
- 주소 옵션(코어 공통): `?reset=1` 처음 상태, `?closet=trial` 체험용 옷장, `?g=F`, `?q=요청`, `?photos=0` 사진 없이 색 카드.
- 저장: 이 브라우저에만, 안마다 다른 이름(`eoul-five-01:v1` … `eoul-five-05:v1`, 05는 시트 목록 `eoul-five-05:sheets:v1` 추가)으로 저장해 한 주소에서 열어도 기록이 섞이지 않는다.
- 상품 사진: 파일이 없다. 브라우저가 판매처 이미지 서버(`image.msscdn.net`)에서 직접 불러온다. **사용 권리는 확인되지 않았다.** 사진 서버를 못 쓰면 색 카드로 바뀐다. 사용자 사진·옷장 자료·키·유료 API·계정은 쓰지 않는다.

## 지킨 규칙
- 가격은 늘 `M/D 수집가`(수집일 가격, 현재가·최저가 아님). 중고는 `newVsUsed()`/`usedSearch()`의 외부 검색 링크이고 "외부 검색 · 매물 확인 안 함"으로 표시한다. 중고 가격·상태·재고·소재·사이즈는 만들지 않는다.
- 0건이면 이유와 다음 선택(조건 빼기 등 `relax()`)만 보여 주고 자동으로 다른 결과를 채우지 않는다. 상황과 덜 맞는 상품은 따로 묶어 표시한다.
- 코디는 "규칙으로 조합한 예시"이고 사진을 합성하지 않는다. 검토자용 설명은 화면 밖(시안 표시 → 고지)에 둔다.

## 알려진 문제
- 01: 모바일 결과 첫 화면에서 후보 카드의 이름·가격은 스크롤해야 보인다. 후보를 끼우면 착장 전체를 다시 계산해 다른 부품도 바뀔 수 있는데(조건은 유지) 화면에 따로 설명하지 않는다. PC 도면은 부품 5개면 칸 안에서 스크롤된다.
- 02: 모델 사진을 상체로 자르지 못했다(원본 대부분 정사각형). 일부 단독 사진은 원본이 회색 바탕이라 흰 칸 안에 회색 상자로 보인다. 스레드는 이 탭(sessionStorage)에만 남는다.
- 03: 흰 옷은 회색 칸에 녹아 회색빛으로 보인다(크게 보기에서 원래 색). 결과 첫 화면에 온전히 보이는 카드는 2개.
- 04: 모바일 결과 무대는 시트 때문에 화면 높이의 34%. 필름 줄 사진은 화면 밖이면 늦게 불러온다. 아이폰에는 한글 명조가 기본으로 없어 한글은 고딕으로 보일 것으로 본다(추정).
- 05: 사진을 못 불러와도 상세 사진 아래 "판매처 대표 사진 · 흰 배경" 문구가 남는다. 시트가 아닌 곳에서 연 상품은 기록에 시트 링크가 없다.
- 공통: 일부 흰 배경 사진은 배경이 완전한 흰색이 아니라 옅은 상자가 보인다(사진 자료 문제).
