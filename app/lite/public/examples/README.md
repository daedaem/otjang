# 체험용 옷 예시 사진

체험용 옷장(`src/core.mjs`의 `TRIAL`)이 그림 대신 보여 주는 사진이다.

- 출처: 대표가 2026-10-27 ChatGPT(OpenAI 이미지 생성)로 직접 만들어 Claude 패션 대화에 첨부했다. OpenAI 이용약관(2026-01-01 시행)상 생성물의 권리는 만든 사람에게 있다. 사람이 찍은 사진처럼 보이게 하지 않도록 앱에서는 '예시 사진'으로 표시한다.
- 규칙(같은 세트로 보이게): 세로 4:5, 아주 연한 회색 배경(#F2F2F4 안팎), 고스트 마네킹 정면, 로고·글자 없음.
- 가공: 원본 1122×1402 PNG를 720×900 WebP(품질 78)로 줄였다. 원본은 저장소에 넣지 않았다.
- 파일 이름은 체험용 옷의 세부 종류 id다(`m-oxford.webp` = 흰 옥스퍼드 셔츠).

| 파일 | 옷 |
|---|---|
| m-oxford.webp | 흰 옥스퍼드 셔츠 |
| m-tee.webp | 흰 무지 티셔츠 |
| m-knit.webp | 네이비 크루넥 니트 |
| m-blazer.webp | 네이비 블레이저 |
| m-chino.webp | 베이지 치노 팬츠 |

남은 9벌(인디고 데님, 브라운 로퍼, 흰 스니커즈, 여성 흰 티셔츠, 베이지 니트, 베이지 트렌치 코트, 블랙 슬랙스, 라이트 블루 데님, 블랙 로퍼)은 대표가 나중에 같은 방법으로 만들어 주기로 했다(10-27). 그 전까지는 비공개 앱에서 '비슷한 상품 사진'(무신사, 권리 미확인)을 표시와 함께 빌려 쓴다.
