# 체험용 옷 예시 사진

체험용 옷장(`src/core.mjs`의 `TRIAL`)이 그림 대신 보여 주는 사진이다.

- 출처: 대표가 이 Codex 대화에서 요청한 브랜드 없는 생성 이미지 14종이다(OpenAI `image_gen`, 2026-10-27~28). 기존 5종은 #103으로 반영됐고, 나머지 9종도 같은 세트로 받아 연결했다. 실제 판매 상품·보유 옷을 촬영한 사진이 아니므로 앱에서는 '예시 사진'으로 표시한다. 개인 사진과 판매처 사진을 가공한 자료는 포함하지 않는다.
- 규칙(같은 세트로 보이게): 세로 4:5, 아주 연한 회색 배경(#F4F4F5), 고스트 마네킹 정면(바지는 곧게 편 정면), 신발은 한 켤레를 오른쪽 측면·살짝 위에서, 로고·글자 없음.
- 가공: 원본 1122×1402 PNG를 720×900 WebP(품질 78)로 줄였다. 원본은 저장소에 넣지 않았다. [manifest.json](manifest.json)에 품목별 원본·WebP SHA256과 크기를 기록했다.
- 파일 이름은 체험용 옷의 세부 종류 id다(`m-oxford.webp` = 흰 옥스퍼드 셔츠).

이 14개 파일로 남성 체험용 8벌·여성 체험용 7벌을 표시한다(흰 스니커즈 1종 공용). 체험용 id·세부 종류·색이 모두 맞을 때만 사용한다. 직접 등록한 실제 내 옷에는 붙이지 않으며 체험용 색·종류를 바꾸면 해당 예시를 계속 보여 주지 않는다. 이 교체로 기본 체험용 항목은 무신사 사진에 의존하지 않는다. 실제 상품 사진 전체의 사용 권리·공개 정책을 해결한 것은 아니다.
