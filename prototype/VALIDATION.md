# 프로토타입 검증 기록

2026-10-11. **기능 프로토타입이며, 요청한 실사 수준의 완성본으로 평가하지 않는다.** 초기 버전은 사용자 시각 평가에서 미달이었고, 개선본도 내부 검토상 의류·목재가 간소화된 모형처럼 보인다. [시각 검토](../docs/design-review/quality-review.md)와 기능 검증을 분리한다. 본인 가상 착장·실제 핏 예측은 아직 구현하지 않았다.

## 현재 구현

- 비대칭 수납장, 창빛, 사선 시점과 모바일 구역 구도를 적용했다. Blender 원본과 웹용 GLB를 제공한다.
- 목재·의류 색상/법선/거칠기 맵을 분리 보존한다. 정적 공간 AO, 웹 GTAO·ACES·4배 MSAA를 적용한다. 별도 조명에서 옷 자체를 돌려 보고 원래 방향으로 돌려놓는다.
- 사진 초안과 보유 기록에 브랜드·상품명·품번·참조 링크·직접 확인 상태를 입력한다. 검색은 명시적 클릭으로 입력한 텍스트만 전달한다. 사진으로 브랜드나 정확한 상품을 알아낸다고 표시하지 않는다.
- 샘플 옷 10벌에 대해 개발 중 작성한 AI 코디 6개를 제공한다. 개인 옷장에 데모 결과를 섞지 않는다.
- 사용자가 기존 AI 대화에서 받은 코디·등록 구매 후보 평가를 가져와 브라우저·개인 백업에 보관한다. 옷장·프로필·후보·요청 조건이 바뀌면 이전 결과를 숨기고 갱신을 안내한다.
- 가져온 응답의 ID·종류·상하의·중복·크기를 검사하고 저장한 요청 스냅샷을 현재 조건과 비교한다. 생성 모델·설명의 사실성·추천 품질을 검증한 것은 아니다. 실제 판매 상품 자동 검색, 실시간 AI API, 로컬 LLM, MCP는 연결하지 않았다.

## 자산과 렌더

Python 3.13.16 / bpy 5.2.2에서 최종 장면을 생성했다. Cycles 포스터는 1600×1050, 64 samples, CPU 4 threads다. `.blend` 재오픈으로 이미지 35개 내장·10슬롯·숨겨진 옷 없음·AO UV1과 원단 UV0 분리를 확인했다. 정적 AO는 움직이는 옷을 제외해 베이크했다.

최종 GLB는 12,030,320 bytes, 374,196 triangles, 140 primitives이다. 단일 HTML은 약 16.27 MiB다. 셔츠 어깨를 관통하던 옷걸이를 수정했고 두 셔츠 어깨 꼭짓점 288개씩을 검사했다. 실제 WebGL 상세에서도 수정 결과를 확인했다.

정지 포스터는 Cycles 이미지다. 웹은 별도 실시간 조명·재질 처리를 사용하므로 두 화면이 동일하지 않다. 자산 내보내기와 빌드 성공만으로 시각 품질이나 저사양 기기 성능을 통과 처리하지 않는다.

## 현재 변경의 검증

테스트 자료는 합성 옷·사진·상품·후기다. 실제 개인 사진을 사용하지 않았다.

모든 브라우저 검사에서 실행 오류와 외부 HTTP 요청은 0건이었다. 이후 모바일 메타 정보의 배경과 선택 시 숨김만 CSS에서 수정했고, 최종 빌드를 다시 실행해 모바일 기본·상세 캡처와 DOM 상태로 가독성·안내 문구 비겹침을 확인했다. 옷 색 변경 검사는 비동기 저장 완료와 뷰어 재생성을 기다리도록 보완했으며, 색 변경·원단 텍스처 보존 주장은 그대로 유지했다.

데스크톱 1440×1000과 모바일 390×844 Chromium에서 검증한다. GPU 없는 클라우드의 SwiftShader 결과이며 실제 사용자 장비 FPS·로딩 시간 측정은 아니다. 소프트웨어 WebGL·Blender는 순차 실행했다. 렌더 검토에서 제기된 상세 화면 헤더 잘림은 최신 DOM과 캡처에서 재현되지 않았고, screenshot 전후 scrollY=0·header y=0/height=60을 확인했다.

## 범위와 재현

실제 복잡한 옷장 사진 인식률, 사용자 체형·얼굴 분석, 가상 피팅, 판매 상품·후기 자동 확보, 실제 상품 재현은 미완료다. 사진 처리는 학습된 의류 모델이 아닌 로컬 영역·대표색 처리이고, 브랜드·종류는 사용자가 확인한다.

관리형 Chromium이 `file://` 탐색을 제한하므로 같은 HTML을 로컬 HTTP로 검증했다. 개인 기기의 파일 직접 열기, 실제 카메라, iOS Safari, 기기별 저장 용량·성능은 미검증이다. IndexedDB 데이터는 브라우저 삭제와 함께 사라질 수 있어 개인 백업을 제공한다.

설치·시작 지침은 클라우드 설정 초안으로 저장했고 이전 설정 단계에서 재실행했다. 현재 인스턴스의 실행 확인과 다른 작업에서의 새 환경 복원은 구분한다. 공개 서비스 준비·전체 PRD 수용 기준·사업성·시각 품질 승인을 뜻하지 않는다.
