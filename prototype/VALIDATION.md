# 프로토타입 검증 기록

확인일: 2026-10-11 (한국 시간). 검증 자료는 합성 옷·사진·상품·후기이며 실제 개인 사진은 사용하지 않았다.

| 검증 | 결과 | 범위 |
| --- | --- | --- |
| `npm ci` | 통과 | 잠금 파일의 개발 의존성 설치 |
| `npm run build` | 통과 | 의존성 없는 단일 HTML 생성, 외부 런타임 파일 없음 |
| `npm test` | 24개 통과, 실패·건너뜀 0 | 도메인·예산·개인/샘플 분리·저장 트랜잭션·백업 검증·이미지 영역·취소 |
| `tools/smoke.mjs` | 44개 확인 통과 | 1440×1000 및 390×844 Chromium, 샘플 시작·검색·편집·코디·저장·착용·상품·후기·판단·실제 구매 전환·재방문·백업 |
| `tools/photo-smoke.mjs` | 8개 시나리오 통과 | 사진 입력·중복·XSS 이름·크롭·묶기/취소·부분 확정·재방문·백업 완전 복원·사진 제외 |
| `tools/photo-edge-smoke.mjs` | 4개 시나리오 통과 | 처리 취소의 부분 결과 보존·분석 중 전체 삭제·저장 공간 부족 후 재시도·잘못된 백업 거절 |
| 최종 변경의 별도 브라우저 확인 | 통과 | 스타일 선택 시 입력 중인 예산·상황 유지, 선택한 초안 삭제 후 재방문에서도 삭제 유지 |
| 네트워크·실행 오류 관찰 | 외부 HTTP 요청 0, 페이지 오류 0 | 테스트의 로컬 서버 요청은 제외. 판매처 링크 클릭은 외부 이동이며 자동으로 실행하지 않음 |
| 시각 확인 | 데스크톱·모바일 스크린샷 확인 | 핵심 화면 가로 넘침 없음. 긴 사용자 이름을 넣은 모바일 격자 문제 수정 후 재검증 |

사진 모듈 별도 Chromium 확인에서는 EXIF 방향 적용·메타데이터 제거, 최대 900px 리사이즈, 손상된 파일 이후 계속 처리, 이미지 디코드 대체 경로를 확인했다. 합성 단색 배경에서의 동작 확인이며 실제 옷장 사진 정확도를 측정한 결과가 아니다.

이 환경의 관리형 Chromium은 `file://` 탐색을 정책으로 막았다. 정책을 변경하지 않고 동일 HTML을 로컬 HTTP로 제공해 위 검증을 수행했다. 개인 기기에서 단일 파일 직접 열기, 실제 모바일 카메라, iOS Safari, 다른 기기의 저장 용량과 인식 품질은 미검증이다.

실제 상품·후기 데이터 확보, 학습된 의류 인식 모델, 본인 사용 효용, 실제 착용감·가상 피팅은 완료로 표시하지 않는다. PRD 전체 통과 또는 공개 서비스 준비 완료를 뜻하지 않는다.
