## 바로 사용하기

`WearNext.html`은 CSS·JavaScript·일러스트가 포함된 단일 파일입니다. 내려받아 최신 Chrome/Edge/Safari 등에서 열어 보세요. 앱 실행에 계정·API 키·유료 서비스가 필요하지 않습니다.

브라우저가 파일 열기나 파일 주소의 저장을 제한하면 Node.js 20 이상에서 다음처럼 실행하세요. 이 방식으로 Chromium 검증을 수행했습니다.

```sh
cd prototype
npm start
```

이후 브라우저에서 `http://127.0.0.1:4173`을 엽니다. 실행은 의존성 설치 없이 가능합니다. 모바일 레이아웃은 390×844 크기의 Chromium으로 검증했으며 실제 iOS/Android 기기 검증은 아직 하지 않았습니다.

처음에는 **샘플 옷장 둘러보기**를 누르면 모든 흐름을 바로 체험할 수 있습니다. **내 옷 사진으로 시작**은 빈 개인 옷장과 미정 예산으로 시작합니다. 사진 여러 장을 넣고 초안의 종류·이름·색을 수정한 뒤 선택한 옷만 확정하세요. 상의와 하의를 각각 한 벌 이상 확정하면 코디를 볼 수 있습니다.

## 실제 동작하는 범위

- 로컬 사진 입력: 파일 선택·끌어놓기·모바일 촬영 입력, 사진 영역·대표색 추출, 크롭, 중복 후보 표시, 묶기·즉시 취소, 부분 확정과 나중 추가.
- 개인 옷장: 검색·분류·수정·오늘 제외·삭제. 샘플 옷장은 개인 옷장과 별도 시작 상태입니다.
- 코디: 스타일·상황을 반영하는 설명 가능한 규칙, 저장과 실제 착용 기록.
- 구매 비교: 보유 옷 연결·비슷한 역할·예산 확인·후기 메모·구매 생각 기록. 직접 기록한 상품의 판매처 이동과 실제 구매 후 보유 전환.
- 저장: IndexedDB, 재방문, 사진 포함/제외 JSON 백업, 검토 후 복원, 전체 삭제. 저장 실패는 성공으로 처리하지 않습니다.
- 반응형 화면, 키보드 접근, 사용자 텍스트 escaping, 가져오기 파일·관계·이미지·URL 검증.

## 프로토타입의 데이터와 한계

샘플 옷은 자체 일러스트입니다. 샘플 상품·가격·후기는 합성 예시이며 실제 판매 상품이나 구매 후기가 아닙니다. 화면에서도 표시합니다. 실제 후보는 사용자가 확인한 상품명·링크·가격·후기 메모를 입력해 비교할 수 있습니다. 상품·후기 자동 수집은 연결하지 않았습니다.

사진 분석은 **단색 배경의 연결된 물체 영역과 대표색을 찾는 로컬 이미지 처리**입니다. 학습된 의류 인식 모델이 아니며 종류·브랜드·정확한 상품명은 인식하지 않습니다. 겹친 옷·복잡한 옷장 사진은 한 영역으로 잡힐 수 있어 직접 수정해야 합니다. 실제 개인 옷장 사진의 인식 품질은 검증 전입니다. 사진에서 찾은 초안은 사용자 확정 전 추천에 사용하지 않습니다.

한 번에 최대 12장, 한 장당 12MB·24MP까지 처리합니다. 저장 이미지는 긴 변 900px 이하 JPEG로 변환하며 EXIF를 제거합니다. 원본 사진 보관 기능은 아닙니다. 사진·파생 이미지는 외부로 보내지 않으며 개인 데이터는 이 저장소에 포함하지 않습니다.

핏 선호는 기록되지만 실측 분석·정확한 사이즈 예측·얼굴 분석·실사 가상 착장은 구현하지 않았습니다. 이 프로토타입의 동작 확인은 PRD 전체 수용 기준이나 개인 효용 검증을 통과했다는 뜻이 아닙니다.

브라우저 데이터 삭제·저장 공간 정리·다른 브라우저/주소로 이동하면 같은 기록을 볼 수 없을 수 있습니다. 백업은 개인 보관용이며 사진 제외 백업에도 프로필·결정 기록은 포함됩니다. 백업 파일의 삭제는 앱에서 수행하지 않습니다.

자세한 관찰 결과는 [검증 기록](VALIDATION.md)을 참고하세요.

## 개발·검증

```sh
cd prototype
npm run build       # 소스에서 WearNext.html과 dist/index.html 생성
npm test            # 도메인·저장·사진 처리 단위 테스트
npm ci              # 브라우저 검증용 Playwright만 설치
npx playwright install chromium
npm start           # 별도 터미널에서 유지
npm run test:browser
node tools/photo-smoke.mjs
node tools/photo-edge-smoke.mjs
```

기존 Chromium을 쓰려면 `CHROMIUM_EXECUTABLE`에 경로를 지정합니다. `PROTOTYPE_URL`로 검사할 로컬 서버 주소를 바꿀 수 있습니다. 개발 환경의 공용 Playwright를 사용할 경우 `PLAYWRIGHT_MODULE`에 그 `index.mjs`의 절대 경로를 지정할 수 있습니다. 테스트 사진은 스크립트가 생성하는 합성 자료입니다.

- `src/main.js`: 화면·흐름·사용자 동작, 직렬 저장과 사진 작업 취소.
- `src/model.js`: 옷장·상품·기록, 추천 규칙, IndexedDB, 검증된 백업.
- `src/photo.js`: 외부 요청 없는 로컬 이미지 처리.
- `src/art.js`: 자체 제작 의류 SVG.
- `tools/build.mjs`: 의존성 없는 단일 HTML 빌드.

원본 인계 앱은 로컬에 보존하고 이 독립 프로토타입으로 새 흐름을 구현했습니다. 모델 선정·실제 자료 확보·본인 실제 사용 평가는 이후 작업으로 남깁니다.
