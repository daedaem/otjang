# 어울 (가칭)

**앱을 열면 바로, 나에게 어울리는 실제 브랜드 아이템과 코디를 추천합니다.**

내 스타일과 가진 옷을 바탕으로 "다음에 무엇을 사면 좋을지"를 실제 판매 상품(브랜드·가격·평점·판매 링크)으로 보여 주는 개인 사이드프로젝트입니다.

## 제품 원칙

1. **입력은 최소로.** 시작할 때 두 번(누구의 옷, 스타일)만 누르면 추천이 나옵니다. 상황·예산은 칩 하나, 가진 옷은 그림을 눌러 표시합니다. 입력 폼은 없습니다.
2. **추천은 실제 상품으로.** 색이나 종류를 제안하는 데서 끝내지 않고, 실제 브랜드 상품을 가격대별로 보여 줍니다.
3. **이유를 한 줄로.** "가진 치노·로퍼와 바로 입을 수 있어요"처럼, 왜 이 상품인지 짧게 설명합니다.
4. **물어보듯 찾기.** "출근용 셔츠 10만원 이하", "청바지에 어울리는 신발"처럼 한 줄로 찾습니다. 앱이 이해한 조건은 칩으로 보여 줍니다.
5. **내 정보는 내 기기에.** 가입이 없고, 옷장·찜·취향은 브라우저에만 저장합니다. 서버가 없습니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 추천 | 한 줄 검색, 상황·예산 칩, 오늘의 코디(실제 상품 조합), 지금 사면 좋은 아이템 |
| 내 옷장 | 가진 옷을 그림으로 눌러 표시 → 추천이 바로 바뀜 |
| 찜 | 찜한 상품과 합계 |

## 실행

```bash
cd app
python3 -m http.server 8000      # http://localhost:8000
node --test                      # 추천 엔진 테스트 (app/ 안에서)
node tools/build.mjs             # app/dist/index.html (파일 하나로 묶은 배포본)
```

구성과 데이터 출처는 [app/README.md](app/README.md)에 정리했습니다.

## 지금 할 수 없는 것

- 가격·재고는 실시간이 아닙니다. 무신사 상품 페이지에서 확인한 시점의 판매가이며, 앱에 확인 날짜를 표시합니다.
- 사이즈·핏은 판단하지 않습니다.
- 추천은 편집자가 정리한 스타일 규칙(아이템별 스타일 점수, 코디 공식)으로 계산합니다. 같은 입력이면 같은 결과가 나오며, 대화형 AI를 쓰지 않습니다.
- 사진으로 옷장을 등록하는 기능은 아직 없습니다. 가진 옷은 그림을 눌러 표시합니다.
