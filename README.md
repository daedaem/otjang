# 웨어넥스트 (WearNext · 가칭)

내 옷장·원하는 스타일·개인 특성·예산을 바탕으로 다음에 보완할 아이템과 실제 상품을 찾고, 후기·코디·구매처까지 한 흐름에서 비교하도록 돕는 개인 사이드프로젝트입니다. 사업 가능성을 검토하면서 백엔드·AI 개발 과정의 근거를 남깁니다.

**현재 단계: 기능 프로토타입 · 시각 품질 재설계.** [프로토타입과 사용 방법](prototype/README.md)에서 사진 등록 → 3D 옷장에서 꺼내 보기 → 코디 → 구매 비교 → 백업 흐름을 직접 체험할 수 있습니다. 실제 상품 자동 수집과 학습 모델 기반 의류 인식은 아직 연결하지 않았습니다.

**[브라우저에서 바로 실행하기](https://daedaem.github.io/otjang/)** — 다운로드 없이 열고 **먼저 둘러보기**를 누르면 샘플 옷장을 볼 수 있습니다.

**제품 방향:** 사진으로 초기 옷장을 구성하는 경험부터 시작해, 본인 전용으로 옷장 보완·상품/후기 비교·코디·구매 판단을 충분히 완성한 뒤 공개 여부를 결정합니다. 패션 커뮤니티는 이후 검증할 성장 가설이며, 현재 사용자 모집이나 공개 운영을 시작한 상태가 아닙니다.

사용자 검토에서 현재 3D 화면의 시각 품질이 부족하다는 피드백을 받았습니다. [Claude 원본과의 비교 및 개선 기준](docs/design-review/quality-review.md)에 차이와 원인을 기록했으며, 디자인 완성으로 표시하지 않습니다.

## 먼저 읽을 문서

- [제품 요약](docs/product-brief.md): 누구의 어떤 고민을 해결하는지
- [PRD v0.4](docs/PRD-v0.4.md): 요구사항·수용 기준·개인화와 데이터의 경계
- [결정 기록](docs/decisions/001-product-direction.md): 사용자 결정과 제안의 구분
- [검증 계획](docs/validation-plan.md): 본인이 실제 사용하며 확인할 것
- [첫 검증과 개인화 판단 기준](docs/first-slice.md): 한 사례의 결과물과 취향에 따른 판단 변화
- [사진 온보딩](docs/photo-onboarding.md): 자동 초안·검토·부분 확정과 로컬 처리 검증
- [상품·후기 확보 상태](docs/data-readiness.md): 직접 확인한 접근 결과와 남은 의존성

## 협업 방식

- 제품 방향과 우선순위는 프로젝트 소유자가 결정합니다.
- Codex는 요구사항 정리, 대안 검토, 구현, 테스트와 문서화를 돕습니다. AI 제안과 사용자 결정을 구분합니다.
- 변경은 목적이 명확한 브랜치와 PR로 남기고, 기능을 요구사항과 수용 기준에 연결합니다.
- 확인한 결과, 아직 검증하지 않은 가설, 알려진 한계를 함께 기록합니다.
- 개인 사진, 인증정보, 개인 옷장 데이터는 공개 개발 기록에 포함하지 않습니다.

작업 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고합니다. PRD 브랜치의 문서는 합의 전 초안입니다.

## 현재 확인한 것

2026-10-11에 전달받은 개인판 v0.3 소스에서 규칙 테스트 **19개**와 기본·빈 옷장 HTML 빌드를 재현했습니다. 이는 기존 규칙과 빌드의 검증이며, 사용자 효용·브라우저 동작·3D 품질의 검증을 뜻하지 않습니다. 기존 인계 앱은 보존하고, 새 흐름은 `prototype/`에 독립 구현했습니다.

프로토타입의 실제 동작·예시 데이터·검증 범위는 [프로토타입 안내](prototype/README.md)에 구분해 기록합니다.
