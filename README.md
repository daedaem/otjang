# 어울 (가칭)

**앱을 열면 바로, 나에게 어울리는 실제 브랜드 아이템과 코디를 추천합니다.**

내 스타일과 가진 옷을 바탕으로 "다음에 무엇을 사면 좋을지"를 실제 판매 상품(브랜드·가격·평점·판매 링크)으로 보여 주는 개인 사이드프로젝트입니다.

## 제품 원칙

1. **입력은 최소로.** 시작할 때 세 단계(누구의 옷 → 스타일 최대 3개 → 자주 사는 브랜드, 건너뛰기 가능)만 고르면 추천이 나옵니다. 상황·예산·"내 브랜드만"은 칩 하나로 바꿉니다. 입력 폼은 없습니다.
2. **추천은 실제 상품으로.** 색이나 종류를 제안하는 데서 끝내지 않고, 실제 브랜드 상품을 가격대별로 보여 줍니다.
3. **이유를 한 줄로.** "가진 치노·로퍼와 바로 입을 수 있어요"처럼, 왜 이 상품인지 짧게 설명합니다.
4. **물어보듯 찾기.** "출근용 셔츠 10만원 이하", "청바지에 어울리는 신발"처럼 한 줄로 찾습니다. 앱이 이해한 조건은 칩으로 보여 줍니다.
5. **내 정보는 내 기기에.** 가입이 없고, 옷장·찜·취향은 브라우저에만 저장합니다. 서버가 없습니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 추천 | 한 줄 검색, 상황·예산·내 브랜드만 칩, 오늘의 코디(실제 상품 조합), 내 브랜드에서 고른 상품, 지금 사면 좋은 아이템 |
| 내 옷장 | 실제 옷 단위로 저장(종류·색·브랜드·사진). 가진 옷만으로 만든 "오늘 뭐 입지?", 하나만 사면 완성되는 코디, 고른 스타일의 기본템 체크. 옷을 넣기 전에는 예시 옷장으로 먼저 써 볼 수 있음 |
| 찜 | 찜한 상품과 합계 |

### 스타일과 브랜드

- 스타일: 남성 6가지(아메리칸 클래식, 아메카지, 시티보이, 미니멀, 댄디, 고프코어), 여성 5가지(아메리칸 클래식, 아메카지, 미니멀, 프렌치 시크, 데일리 캐주얼). 세 개까지 고르고, 먼저 고른 스타일을 더 반영합니다.
- 브랜드: 폴로 랄프 로렌, 브룩스 브라더스, 오어슬로우, 리바이스, 레드윙, 칼하트, 디키즈, 아웃스탠딩, 파르티멘토, 프리즘웍스, 무신사 스탠다드, 노스페이스, 파타고니아 등 60여 개. 고른 브랜드를 먼저 추천하고, "내 브랜드만"을 켜면 그 브랜드 상품만 보여 줍니다.

### 내 옷장에 옷을 넣는 세 가지 방법

1. 종류 사진을 누르고 색(필요하면 브랜드)을 고릅니다.
2. 사진을 고르면 가운데 색을 짐작해 색을 미리 골라 둡니다. 사진은 이 기기(IndexedDB)에만 저장합니다.
3. 추천 상품 화면에서 "이 상품 있어요"를 누르면 그 상품 그대로 옷장에 들어갑니다.

사진 없이 넣은 옷은 같은 종류·같은 색(또는 아주 가까운 색)의 상품 사진으로 보여 주고 "비슷한 사진"이라고 표시합니다. 맞는 색의 상품이 없으면 그 색의 카드로 보여 줍니다. 옷 상세에서 "내 사진 넣기"로 언제든 내 사진으로 바꿀 수 있습니다.

옷을 넣기 전에는 "예시 옷장으로 먼저 보기"로 고른 스타일의 예시 옷 몇 벌을 넣어 "오늘 뭐 입지?"를 미리 써 볼 수 있습니다. 예시 옷에는 '예시'라고 표시하고, 내 옷을 하나 넣으면 사라집니다.

### 저장과 백업

- 옷장·찜·취향은 브라우저(localStorage `eoul:v2`), 옷 사진은 IndexedDB에 저장합니다. 저장 공간이 부족해 저장하지 못하면 옷을 넣은 것처럼 보이지 않게 되돌리고 알려 줍니다. 저장을 막은 브라우저(사생활 보호 모드 등)에서는 화면 위에 "창을 닫으면 사라진다"고 표시합니다.
- 브라우저 정보를 지우거나 기기를 바꾸면 옷장이 사라질 수 있어, 프로필과 옷장 화면에서 **백업 파일**(옷장·찜·취향·사진을 담은 JSON 한 개)을 받고 다시 불러올 수 있습니다. 백업 파일에는 옷 사진이 들어 있으니 내 기기나 내 클라우드에만 보관하세요.

## 실행

```bash
cd app
python3 -m http.server 8000      # http://localhost:8000
node --test                      # 추천 엔진 테스트 (app/ 안에서)
node tools/build.mjs             # app/dist/index.html (파일 하나로 묶은 배포본)
```

구성과 데이터 출처는 [app/README.md](app/README.md)에 정리했습니다.

## 지금 할 수 없는 것

- 가격·재고는 실시간이 아닙니다. 무신사 상품 페이지에서 확인한 시점의 판매가이며, 앱에 확인 날짜를 표시합니다.
- 사이즈·핏은 판단하지 않습니다.
- 추천은 편집자가 정리한 스타일 규칙(아이템 종류 68개의 스타일 점수, 코디 공식 32개, 색 조화 규칙)으로 계산합니다. 같은 입력이면 같은 결과가 나오며, 대화형 AI를 쓰지 않습니다.
- 사진으로 옷 종류를 알아내지는 못합니다. 사진에서는 색만 짐작하고, 종류는 사용자가 고릅니다. 사진이 없는 옷에 보여 주는 "비슷한 사진"은 같은 종류·색의 판매 상품 사진일 뿐, 실제 옷의 모양·핏과 다를 수 있습니다.
- 브랜드 목록 화면에서 모은 상품은 이름의 단어로 종류를 자동 분류했습니다. 구두주걱·수영복처럼 옷이 아닌 상품과, 이름이 다른 종류를 가리키는 상품이 섞이지 않는지 테스트로 확인하지만, 일부 상품은 종류나 색이 실제와 다를 수 있습니다.
- 저장은 브라우저에 의존합니다. 브라우저가 오래 쓰지 않은 사이트의 저장 정보를 지우는 정책을 쓰면 옷장이 사라질 수 있으니 백업 파일을 받아 두세요.
