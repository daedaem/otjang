# 옷장들이 (가칭)

내 옷장을 바탕으로 가진 옷을 더 잘 활용하고, 다음 한 벌을 고르는 일을 돕는 개인 사이드프로젝트입니다. 사업 가능성을 검토하면서 백엔드·AI 개발 과정의 근거를 남깁니다.

**현재 단계: PRD 검토.** 본인 전용으로 코디와 구매 판단을 충분히 완성한 뒤 공개 여부를 결정합니다. 패션 커뮤니티는 이후 검증할 성장 가설이며, 현재 사용자 모집이나 공개 운영을 시작한 상태가 아닙니다.

## 협업 방식

- 제품 방향과 우선순위는 프로젝트 소유자가 결정합니다.
- Codex는 요구사항 정리, 대안 검토, 구현, 테스트와 문서화를 돕습니다. AI 제안과 사용자 결정을 구분합니다.
- 변경은 목적이 명확한 브랜치와 PR로 남기고, 기능을 요구사항과 수용 기준에 연결합니다.
- 확인한 결과, 아직 검증하지 않은 가설, 알려진 한계를 함께 기록합니다.
- 개인 사진, 인증정보, 개인 옷장 데이터는 공개 개발 기록에 포함하지 않습니다.

작업 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고합니다. PRD 브랜치의 문서는 합의 전 초안입니다.

## 현재 확인한 것

2026-10-11에 전달받은 개인판 v0.3 소스에서 규칙 테스트 **19개**와 기본·빈 옷장 HTML 빌드를 재현했습니다. 이는 기존 규칙과 빌드의 검증이며, 사용자 효용·브라우저 동작·3D 품질의 검증을 뜻하지 않습니다. 소스 등록과 추가 환경 작업은 PRD 범위를 정한 뒤 이어갑니다.

실제 상품 자동 추천, 실사 착장, 정확한 핏 판정, 다중 사용자 서버는 완료된 기능으로 소개하지 않습니다.
