# 옷잡이

**대충 말해도, 나한테 맞는 옷을 찾아 줘요.**

길잡이가 길을 잡아 주듯, 옷잡이는 옷 고르는 길을 잡아 줘요.
내 옷을 하나씩 잡아 모으고, 오늘 입을 옷과 다음에 살 옷을 같이 골라요.

> 옷잡이는 가칭이에요. 상표 확인 전이라 바뀔 수 있어요.
> 지금은 대표 혼자 아이폰에서 써 보는 **비공개 시험판**이에요. 공개 서비스가 아니에요.

<br>

## 이런 걸 할 수 있어요

**한 줄로 찾기**
"출근용 셔츠 10만원 이하"처럼 말하면, 조건에 맞는 실제 상품을 골라 줘요.
맞는 게 없으면 "없어요"라고 말하고, 다른 걸 몰래 끼워 넣지 않아요.

**내 옷장 모으기**
브랜드나 상품 이름으로 찾아서 옷장에 넣어요. 목록에 없는 옷은 직접 등록해요.
옷이 늘수록 입을 수 있는 코디 수가 같이 늘어나요.

**오늘 날씨 코디**
아침에 앱을 열면 오늘 기온과 비 소식에 맞춰 내 옷으로 코디를 골라 줘요.
맞는 겉옷이 없으면 그날 필요한 옷을 실제 상품으로 보여 줘요.

**코디 상담**
"베이지 니트에 어울리는 바지는?"처럼 물어보면 AI가 답해요.
옷과 코디 이야기만 해요. 지난 상담은 다시 열어서 이어 물을 수 있어요.

**새 옷도, 이미 있는 옷도**
새 상품은 판매처로, 중고는 국내 4곳·해외 5곳 검색으로 바로 이어져요.

**산 것과 안 산 것 기록**
샀어요 · 보류 · 안 살래요를 남겨 두면, 나중에 한눈에 다시 볼 수 있어요.

## 우리가 지키는 약속

| 약속 | 이렇게 지켜요 |
|---|---|
| 내 사진은 내 기기에만 | 옷장 사진은 밖으로 보내지 않아요. 상담에도 사진은 안 보내요 |
| 모르는 건 지어내지 않기 | 가격은 언제 확인한 가격인지 같이 적어요. 재고·소재·사이즈는 만들지 않아요 |
| 몰래 긁어 오지 않기 | 상품 정보는 크롤링하지 않고, 공식 API와 허락된 공급처로만 가져와요 |
| 비밀은 저장소 밖에 | API 키와 비밀번호는 저장소·문서·채팅에 두지 않아요 |

<br>

## 지금 어디까지 왔나요

| 영역 | 상태 |
|---|---|
| 설치 앱 (`app/lite`) | 대표 아이폰에서 쓰는 중. 본인만 로그인해서 열 수 있어요 |
| AI 순위·상담 | Claude Haiku로 연결. 하루·한 달 사용 횟수에 한도가 있어요 |
| 날씨 코디 | 현재 위치나 고른 지역의 실제 날씨로 동작해요 |
| 상품 찾기 | 국내는 애드픽 공식 API, 해외는 Rakuten 검색을 연결했어요 |
| 수집 상품 937개 | 화면 시험용이에요. 사진 사용 권리를 확인하지 않아서 공개에 쓰지 않아요 |
| 직접 등록 공유 | 같은 옷을 여러 명이 등록하면 모두 검색할 수 있게 하는 서버를 준비했어요 |
| 아직 안 된 것 | 실제 아이폰에서의 꼼꼼한 확인, 커뮤니티, 아침 알림, 공개 출시 |

자세한 상태는 [대표 요구사항](docs/owner-requirements.md)에 늘 최신으로 적어요.

<br>

## 직접 실행해 보기

Node 22가 필요해요.

```bash
# 설치 앱
cd app/lite
npm ci
npm test              # 서버 함수 검사 (가짜 AI·가짜 DB, 비용 0원)
npm run build         # dist/ 만들기
node dev.mjs --fake   # http://127.0.0.1:8790 에서 가짜 AI로 둘러보기

# 첫 버전 웹 앱과 엔진
cd app
npm ci
npm test
```

실제 AI·로그인·DB 설정은 [설치 앱 안내](docs/lite-app-setup-20261020.md)를 따라요.
